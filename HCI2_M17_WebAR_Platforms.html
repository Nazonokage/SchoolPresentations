FAQs
Common Questions Answered
❓ What is the main difference between VR and AR?
Virtual Reality (VR)
~75% virtual. Creates a completely immersive simulated environment. Requires a headset to block out the real world. User moves within a fictional space.
Augmented Reality (AR)
~25% virtual. Augments the existing real-world scene. Does NOT require a headset. Keeps the user in contact with the physical world.
❓ Why is AR becoming so popular in e-commerce?
AR is exceptional for showcasing detailed 3D product models in the user's own environment. When customers can see how a product works, fits, or looks in their specific space using AR, it dramatically increases purchasing confidence and reduces returns.
❓ Do I need to know JavaScript to build WebAR?
Not necessarily. While professional tools like 8th Wall require JavaScript, SaaS platforms like Augmania, PlugXR, and XR.+ provide drag-and-drop visual editors. You can build fully interactive AR experiences by uploading 3D assets and configuring triggers — no code required.
❓ What makes EasyAR unique compared to others?
EasyAR's Cloud Spatial Map feature enables city-scale AR — meaning it can recognize and track real-world locations across an entire city, not just a single image or object. This makes it uniquely suited for cultural tourism, education, and smart city applications.
Skill-Building Activity · Guided Drill
CSS 3D Perspective Demo
Practice how WebAR engines “map” 3D space using CSS perspective. Save as AR.html and move the slider!
html — AR.html
<!DOCTYPE html>
<html>
<head>
  <title>Augmented Reality Sample</title>
  <script>
    // Function to change perspective depth
    function changePersp(value) {
      // Change CSS perspective of the wrapper div
      document.getElementById('div1').style.perspective = value + "px";
      // Update the text display
      document.getElementById('persp').innerHTML = value;
    }
  </script>
  <style>
    #div1 { position:relative; height:200px; width:200px;
             margin:50px; padding:10px; border:1px solid red; }
    #div2 { padding:50px; position:absolute; border:1px solid red;
             background-color:green; transform:rotateX(45deg);
             text-align:center; }
    #h1   { background-color:lemonchiffon; text-align:center;
             font-style:oblique; }
  </style>
</head>
<body onload="changePersp(200);">
  <div id="h1"><h1>Augmented Reality Sample</h1></div>
  <div id="div1">
    <div id="div2">HELLO Welcome to HCI</div>
  </div>
  <br>
  Change Perspective:<br>
  <input type="range" min="45" max="2000" value="200"
         onchange="changePersp(this.value)">
  <br>
  <strong>Current Perspective Depth:</strong> <span id="persp"></span>px
</body>
</html>
Guided Drill · Breakdown
How the Perspective Demo Works
📌 CSS perspective Property
The perspective CSS property sets how far the user's eye is from the 3D plane of the element.
  • Low value (45px) — very distorted, like being very close to the scene
  • High value (2000px) — nearly flat, like viewing from far away
  • This is the exact principle WebAR engines use to calculate depth
🔄 transform: rotateX(45deg)
Rotates #div2 45 degrees around the X-axis (tilts it away from the viewer). The perspective on the parent determines how 3D this tilt appears.

In real WebAR, frameworks like 8th Wall apply similar transforms based on actual camera position data — automatically.
⚡ changePersp(value) Function
  • Called on page load via onload="changePersp(200)"
  • Called on slider move via onchange="changePersp(this.value)"
  • Reads the slider value and applies it to #div1's style.perspective
  • Updates the #persp span to show the current depth value
🔗 Connection to WebAR
This drill simulates the core concept: AR engines calculate the viewer's distance and angle from the real world, then adjust the perspective depth of virtual objects to make them appear correctly anchored in 3D space.

CSS perspective is the simplified, browser-native version of that math.
