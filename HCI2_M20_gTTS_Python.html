Lesson Preview · What is gTTS?
Google Text-to-Speech — Reviewed
Building on M19 — this module is entirely hands-on. We write a complete Python program that converts any text into a playable MP3 file.
📋 What gTTS Is
gTTS = Google Text-to-Speech.

A Python library and CLI tool that interfaces with the Google Translate TTS API.
  • Output: Returns an .mp3 audio file
  • Languages: English, Hindi, Tamil, French, German & more
  • Speed: Fast or slow (set via slow=True / False)
  • Limit: Cannot change voice type (male/female) in the free API

Step-by-Step Guide · Steps 1 & 2
Install & Import
1
Install gTTS on Your System
Before writing any code, install the gTTS module using Python's package manager pip. Open your Terminal, Command Prompt, or PowerShell and run:
bash — terminal
pip install gTTS
💡 pip is Python's package management system — it is NOT the same as Python itself. It is used exclusively to install and manage third-party packages like gTTS. Most modern Python installs include pip automatically.
2
Import gTTS to Your Program
Inside your Python script, import the gTTS class and the built-in os module. The os module lets Python interact with your system's audio player to play the output file.
python
from gtts import gTTS
import os
❓ Why two imports?
gTTS handles the text-to-speech conversion and MP3 creation. os is needed later to call the system audio player (mpg321) to actually play the file back. Neither can do the other's job.
Step-by-Step Guide · Steps 3 & 4
Get Input & Create the Object
3
Get User Input
Ask the user for the text they want to convert. Use Python's built-in input() function to capture their response and store it in a variable.
python
# Ask the user for the text to convert
text = input("Enter a word or sentence: ")
4
Create a Text-to-Speech Object
Pass the user's text into the gTTS constructor to create an audio object. Specify the language and speed as parameters.
python
# Create the gTTS object
tts = gTTS(text=text, lang='en', slow=False)
📌 Parameter Breakdown
text=text — the string to synthesize
lang='en' — language code (English)
slow=False — normal speed · True = slower
🌐 Language Code Examples
'en'English 'es'Spanish 'fr'French 'de'German 'hi'Hindi 'tl'Filipino
Step-by-Step Guide · Steps 5 & 6
Save & Play the Audio
5
Save the Audio File
Call .save() on the gTTS object to write the MP3 file to disk. The file will be saved in the same folder where your Python script is running.
python
# Export the audio object to an mp3 file
tts.save("output.mp3")
6
Play the Audio File
Use os.system() to tell the operating system to play the MP3. On Windows, this requires mpg321 — a lightweight MP3 player that must be installed and added to your PATH.
python
# Play the audio file (requires mpg321 on Windows)
os.system("mpg321 output.mp3")
⚠️ Windows users: Download mpg321.exe from its official website and add it to your system's PATH environment variable. Without this, os.system() will not find the player and your program will crash at this step.
Full Code · Complete Project
All 6 Steps Together
Save as tts.py, run with python tts.py, and type a sentence when prompted.
python — tts.py
from gtts import gTTS
import os

# 1. Get the text input from the user
text = input("Enter a word or sentence: ")

# 2. Create the text-to-speech object
#    lang='en' sets it to English, slow=False sets it to normal speed
tts = gTTS(text=text, lang='en', slow=False)

# 3. Save the audio file to disk
tts.save("output.mp3")

# 4. Play the audio file
#    Requires 'mpg321' installed & added to PATH on Windows
os.system("mpg321 output.mp3")
💡 Pro Tip — Change the Language
Replace lang='en' with any language code to synthesize in a different language. Make sure your text variable contains text written in that language for best results.

Example: lang='es' for Spanish, lang='fr' for French.
⚠️ Common Crash Fix
If your program crashes at os.system("mpg321 output.mp3"):
  • Check that mpg321.exe is downloaded
  • Verify it is in a folder on your PATH
  • Try running mpg321 output.mp3 directly in terminal first

FAQs
Common Questions Answered
❓ How do I install pip on my system?
Most modern Python installations come with pip pre-installed. If missing, run python get-pip.py in your terminal. This installs or upgrades pip along with setuptools and wheels.

Tip: Avoid using a system-managed Python installation; use a standalone Python install to avoid conflicts.
❓ Is pip the same as Python?
No. pip is a package management system written in Python — used exclusively to install and manage third-party software packages (like gTTS) into your Python environment. The Python Software Foundation officially recommends pip for installing applications and dependencies during deployment.
❓ Does gTTS work offline?
No. gTTS uses the web-based Google Translate API, so your computer must have an active internet connection when you run the script. For offline TTS in Python, use pyttsx3 instead (covered in Module 19).
❓ My program crashes on os.system(). Why?
This usually means mpg321 is not installed or not added to your PATH environment variable.
  • Download mpg321.exe and place it in a recognized folder
  • Add that folder to your PATH, or specify the full file path in os.system()
  • Test in terminal first: type mpg321 output.mp3 directly
