Topic 1 · Definition
What Is a Map API?
A Map API (also called Mapping API) provides location intelligence for software developers — the foundational building block for anything that needs to know where.
🗺️ Core Purpose
A Map API is the foundational block for:
  • Creating location-based applications and services
  • Building feature-rich, interactive maps
  • Retrieving geographic-related data
🔗 Why Maps Matter in AR
AR doesn't just need to see things — it often needs to know where things are. Map APIs bring geographic intelligence to AR experiences, powering:
  • Location-based AR (Pokémon GO style)
  • Navigation overlays
  • Real-world coordinate anchoring
💡 Why Are Maps So Valuable?
Maps provide interactive and informative alternatives to plain text. They are an easy-to-use, cost-effective tool for branding, storytelling, and engaging customers — especially for small businesses. A single map on a landing page often converts better than paragraphs of address text.
Topic 1 · Features
What Modern Map APIs Offer
Typical features you get out of the box with a modern Map API.
📍
Geocoding
Convert a human address (“1600 Amphitheatre Pkwy”) into GPS coordinates (Lat/Lng).
🌐
Reverse Geocoding
Take coordinates and return the nearest human-readable address or place name.
📱
Geolocation
Find the user's current physical position using GPS, Wi-Fi, or IP address triangulation.
🧭
Directions & Nav
Compute routes between points with turn-by-turn instructions, ETAs, and traffic data.
👋
Touch Interaction
Panning, zooming, tapping — native gesture support built into every embed.
🗾
Multiple Map Types
Terrain, satellite, street view, hybrid — swap views to fit the use case.
🎨 Customization — Overlays & Data Layers
Developers can heavily customize maps with context- and industry-relevant data overlays:
  • Widgets, gadgets, and interactive markers
  • Custom graphics, images, and popups
  • Data visualization (heatmaps, traffic layers, choropleth maps)
  • Custom control objects (zoom bars, layer toggles, drawing tools)
Topic 1 · Deep Dive
Geocoding vs Reverse Geocoding
These two operations power almost every location-aware feature. Understanding them is essential.
➡️ Geocoding — Address to Coordinates
📥 Input: "Rizal Park, Manila, PH"
⬇️
Output: 14.5825° N, 120.9793° E
Used when the user types an address and you need to place a pin on the map.
⬅️ Reverse Geocoding — Coordinates to Address
📥 Input: 14.5825° N, 120.9793° E
⬇️
Output: "Rizal Park, Manila, PH"
Used when the phone reports GPS coords and you need to show the user a readable place name.
🔑 Real-World Example 1Airbnb geocodes hosts' addresses to pin their listings on the map.
🔑 Real-World Example 2Uber reverse-geocodes your pickup GPS to show “you're at 5th Ave.”
🔑 Real-World Example 3Instagram reverse-geocodes photo EXIF data to auto-suggest location tags.
Bonus · Browser Geolocation API
Getting the User's Location in JavaScript
Modern browsers include a built-in Geolocation API (navigator.geolocation) — no external library needed. This connects seamlessly to any Map API.
javascript — geolocation demo
// Check if geolocation is supported by the browser
if (navigator.geolocation) {
  navigator.geolocation.getCurrentPosition(
    // Success callback
    function(position) {
      const lat = position.coords.latitude;
      const lng = position.coords.longitude;
      console.log("Latitude: " + lat);
      console.log("Longitude: " + lng);
      // Now feed these coords into your Map API!
    },
    // Error callback
    function(error) {
      console.error("Location access denied or unavailable");
    }
  );
} else {
  alert("Geolocation is not supported by this browser.");
}
🔐 Permission Required
Browsers always ask the user for permission before sharing GPS coords — a fundamental privacy safeguard. If the user denies, the error callback fires. Never assume location access.
💡 This is Location-Based AR's Foundation
This exact getCurrentPosition() pattern is how Pokémon GO knows where to spawn creatures, and how tourism AR apps trigger content when you enter a specific neighborhood. Coordinates → Map API → AR overlay.

Topic 3 · The No-Code Way
Embed a Map with an iframe
Two ways to integrate a Google Map into HTML: with an API key (professional, customizable) or without a key using the Embed method (quick, easy). Here's the 3-step no-code approach.
1
Search for Your Desired Location
Go to maps.google.com and search for the specific location you want to display — e.g., “Iloilo City, Iloilo”. Wait for the pin to drop on the map.
2
Copy the Embed Code
  • ▸Click the “Share” button (side panel or top left)
  • ▸In the pop-up, click the “Embed a map” tab
  • ▸Google provides an <iframe> snippet — click “Copy HTML”
3
Paste It Inside Your HTML Page
Open your HTML file in a code editor and paste the copied <iframe> code wherever you want the map to appear (usually inside <body>).
html — sample iframe
<iframe
  src="https://www.google.com/maps/embed?pb=!1m18!..."
  width="600" height="450"
  style="border:0;"
  allowfullscreen="" loading="lazy"></iframe>
💡 Pro Tip: Resize the map by adjusting the width and height attributes inside the <iframe>. Use width="100%" for responsive layouts.
Advanced Drill · Interactive Map
The JavaScript AR Map Prototype
The <iframe> method is static. For AR-focused apps, you need interactivity. This prototype combines a location prompt (simulating location-based AR) with a Google Maps redirect. Save as map.html.
html — map.html
<!DOCTYPE html>
<html>
<head>
  <title>AR Map Prototype</title>
</head>
<body>
  <h2>AR Map Prototype</h2>
  <p>Press the button to check the map</p>

  <!-- Button triggers the JavaScript function -->
  <button onclick="map_data()">Map it</button>

  <!-- Paragraph to display status messages -->
  <p id="demo"></p>

  <script>
    function map_data() {
      // Ask the user for a location
      let x = prompt("Enter location");

      // Check if input matches target location
      if (x == "iloilo") {
        // Open Google Maps URL in a new window
        window.open("https://www.google.com/maps/place/Iloilo+City,+Iloilo/...");
      } else {
        // Display error message
        document.getElementById("demo").innerHTML = "404! Location not found.";
      }
    }
  </script>
</body>
</html>
Advanced Drill · Breakdown
How the Prototype Works
🎯 Line-by-Line Logic
  • onclick="map_data()" — the button click event triggers the JS function
  • prompt("Enter location") — opens a modal asking for text input
  • if (x == "iloilo") — checks if the user typed the target keyword
  • window.open(URL) — opens the Google Maps location in a new tab
  • innerHTML = "404!..." — error path if no match
🔗 Why This Is “AR-Like”
This mimics location-based AR flow: trigger → check location → display content. Real AR apps replace the prompt() with actual GPS data via navigator.geolocation (from earlier slide), and replace window.open() with 3D content rendering.
🚀 Level-Up Challenge Ideas
  • Replace "iloilo" with your own city or landmark
  • Change the URL to point to your specific location
  • Customize the error to “Location not found. Please try another city.”
  • Add multiple valid locations using else if chains
  • Combine with the navigator.geolocation API for real GPS
⚠️ Limitations to Know
This prototype is case-sensitive (typing “Iloilo” won't match). Add x.toLowerCase() before comparison to fix. Also, prompt() is old-school — modern apps use HTML form inputs for better UX.

FAQs
Common Questions Answered
❓ What does a Map API do?
A Map API provides prepackaged pieces of code that let you quickly include dynamic, interactive maps in websites or mobile apps. They're available for Android, iOS, web browsers, and as HTTP web services for backend data integration.
❓ Which Map API is best?
Depends on your needs:
  • Google Maps — industry standard, best imagery/features (but costly at scale)
  • Mapbox — ~50k free views/month, best for custom styling
  • Bing Maps — ideal within Microsoft/Azure ecosystems
  • Foursquare — ~99.5k free calls/month, best for venue analytics
❓ Geocoding vs Reverse Geocoding?
Geocoding turns a human address (“1600 Amphitheatre Pkwy”) into GPS coordinates (Lat/Lng). Reverse Geocoding does the opposite — takes coordinates and returns the nearest human-readable address.
❓ Do I need an API key for Google Maps?
For professional/production websites: yes — sign up for Google Cloud Platform and generate a key.

For simple demos or hobby projects: no — use the “Embed a map” <iframe> method without a key.
