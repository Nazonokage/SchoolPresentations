## Teaching scope: understanding and independent implementation

Coursework does not require AI agents, AI-assisted coding or model-provider integration. Students trace examples, write their own modifications, explain decisions and demonstrate success and failure behavior. Imported AI research is historical reference material, not an instruction to use those tools. ADET M16 teaches a deterministic rule-based API and offline fallback. Hermes refers to the React Native JavaScript engine.
