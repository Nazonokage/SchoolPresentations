# ADET teaching modules

**Current finals sequence:** M19 rehearsal, [M20 defense quiz and essays](ADET_M20.md), then [M21 solo mini-capstone announcement and readiness](ADET_M21.md). Alternating assessments apply through M19. If finals has only two teaching meetings, assign M20 as individual preparation between M19 and M21. Keep summative and periodical exam time separate.
