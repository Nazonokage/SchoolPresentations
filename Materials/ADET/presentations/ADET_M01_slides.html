Remember

Metro runs your code. Your editor and npx tsc --noEmit check types.

Big picture

Your computer serves, your phone shows

Metro packs your code on the computer. Hermes is the JavaScript engine that runs it on the phone (not an AI tool).

Expo Go is a prebuilt native app that opens your project. A development build is your own host app with extra native libraries.

Tools

Install and check your tools

  • Node.js (LTS): runs JavaScript on your computer
  • npm: comes with Node; downloads packages
  • VS Code: your editor
  • Expo Go: on your phone
  • Emulator / simulator: optional
node -v
npm -v

Each prints a version number. “Not recognized”? Install Node, then close and reopen the terminal.

Create

Create your project

npx create-expo-app@latest ADET-M01-LASTNAME --template blank-typescript@sdk-58 --no-agents-md
cd ADET-M01-LASTNAME

What this does

blank-typescript: your first screen is App.tsx.

@sdk-58: the course Expo version.

--no-agents-md: skips an extra AI-agent file. We do not use AI agents.

Watch out

A Router-based template uses route files, not App.tsx. If you picked it by accident, create the course project again instead of guessing where the code goes.

Run

Start the server and open the app

npx expo start

Ways to open

  • Phone: scan the QR with Expo Go and follow any sign-in prompt
  • Android emulator: press a
  • iOS simulator: press i

Rules

  • Phone and computer on the same working network
  • --tunnel: online fallback only, needs internet
  • Prepared lab with no internet: npx expo start --offline on a working local network
Versions

The SDK must match your Expo Go

Course baseline (tested Nov 6–7, 2026)

Expo SDK 58 (expo 58.0.23), React Native 0.88.1, React 19.3.0, TypeScript 6.0.3, Node 24.18.1, npm 11.16.0. Use the prepared starter and lockfile.

Local compile and bundle passed. Phone and network checks are still pending.

Mismatch?

“Project is incompatible”: ask your instructor to check your Expo Go against the SDK 58 baseline (expo.dev/go). A physical iPhone may not install an older Expo Go. Do not change the course SDK yourself.

Read before typing

The baon program

import { View, Text } from "react-native";

export default function App() {
  const greeting = "Hello, ADET!"; // Constant: a name
  const prices = [25, 35];
  function calculateBalance(budget: number) {
    let remaining = budget; // Variable: changes
    for (const price of prices) {
      remaining -= price; // Loop: same step each
    }
    return remaining; // Function: return result
  }
  const balance = calculateBalance(50);
  let message: string;
  if (balance >= 0) {
    message = "Change: PHP " + balance;
  } else {
    message = "Kulang: PHP " + Math.abs(balance);
  }
  return (
    <View
      style={{
        flex: 1,
        padding: 24,
        paddingTop: 60,
        gap: 12,
      }}
    >
      <Text>{greeting}</Text>
      <Text>{message}</Text>
    </View>
  );
}
IdeaHere
const / letprices fixed; remaining changes
Functiontakes a budget, returns the balance
Loopsubtracts each price once
Condition>= 0 picks Change or Kulang
Typebudget: number
Trace it

Budget 50 → Pay 25 → Pay 35 → Short 10

Predict first

With PHP 50 and prices 25 and 35, change or shortage?

StepCalculationremaining
Startbudget50

Second price25 − 35−10

Try it

Budget 80 gives Change: PHP 20. A negative balance is a valid result here, not a crash.

Misconception

“TypeScript validates every real input at runtime.”

Types help check your source. Real outside data still needs validation.

Run and check

Run it, then type-check it

Expected on the phone

Hello, ADET!

Kulang: PHP 10

  • Save: Fast Refresh usually updates the screen. Some edits remount or reload.
  • Metro transpiles but does not type-check. Run the check yourself after replacing App.tsx:
npx tsc --noEmit

No output means no type errors.

Troubleshooting

When something goes wrong

QR opens, won’t load

Same working network? --tunnel is online only.

Incompatible project

SDK and Expo Go differ. Ask your instructor; do not change the course SDK.

Unable to resolve module

Check the import spelling and prepared dependencies first. Extra packages need online preparation.

Type error

Run npx tsc --noEmit. Fix the line it names.

Runtime error

A red screen while the app runs. Read the message and file.

Stale screen

Save again, then npx expo start --clear.

Optional online homework

Add a package safely (not assessed)

npx expo install expo-constants
npx expo-doctor@latest
npx expo install --check
npx expo install --fix

Needs internet, so it is not part of the offline lab. --check lists out-of-date packages and --fix aligns them. Restart the server after installing, and read the package docs for app.json settings or development-build needs.

Analogy & mistakes

Parang karinderya

Node = kalan · Expo = kumpletong kitchen set · Metro = tagaluto ng order · phone = customer. Kapag nagbago ang recipe (code) at nag-save, nakikita ng customer ang bagong luto.

Use case: a student checks whether today’s baon covers two purchases. The screen explains a shortage instead of crashing.

Common mistakes

  • npm install where npx expo install is needed
  • Phone and computer on different networks
  • Editing the wrong file after choosing a Router template
  • Assuming Metro checks types

Activity · Individual coding

Your first project

The task

  1. Create your own project (blank TypeScript) with your own greeting
  2. Change the budget to 80 and add a third price of 15. Show the balance and explain each subtraction. Also test a budget equal to the total spending
  3. Run npx tsc --noEmit; explain how it differs from starting Metro
  4. Failure case: misspell react-native in the import, copy the red error, then fix it

Check yourself

Budget 80 with prices 25, 35, 15 → Change: PHP 5.

Budget 75 → Change: PHP 0.

Submit

Source, exact commands, one screenshot of a successful run, the error from step 4, and which line caused the difference.

Assessment

Three equal-point ways to do it

1 · Offline lab

Prepared starter with node_modules, START-LAB.cmd, only your App.tsx changes. No installs in class. If no phone route passes the smoke test, use mode 3.

2 · Prepared laptop

Set up before class, bring your laptop, submit source, package.json, lockfile and a README with commands. Never upload node_modules or secrets.

3 · Written alternative

Trace budgets 50, 60 and 80, then add price 15. Name the loop, condition and function input and return, and a type-error fix. Table plus 150–250 words.
