Main lesson

State remembers; a setter requests an update

const [seconds, setSeconds] = useState(0);
setSeconds((current) => current + 1);

Follow the value

  • seconds holds the current count.
  • setSeconds schedules its next value.
  • The updater receives the previous count.
  • An ordinary local variable does not request a render.

Main lesson

Render, commit, then synchronize

Render and commit

Render describes the UI. Commit applies the result. Effects synchronize with resources outside rendering.

Cleanup

When dependencies change, old cleanup runs before new setup. On removal, cleanup releases the resource.

Development Strict Mode may probe setup and cleanup again.

Main lesson

One interval needs one cleanup

useEffect(() => {
  const intervalId = setInterval(
    () => setSeconds((current) => current + 1),
    1000
  );
  return () => clearInterval(intervalId);
}, []);

Why these lines matter

  • []: no reactive values to resynchronize here.
  • The return function releases this interval.
  • Starting an interval in render creates extra work.
  • Callbacks can be delayed; this is not an accurate clock.

Guided program

The complete lifecycle checkpoint

import { useEffect, useState } from "react";
import { AppState, View, Text, Button } from "react-native";

// Count delivered interval callbacks, not precise elapsed time.
function Timer() {
  const [seconds, setSeconds] = useState(0);

  useEffect(() => {
    console.log("Timer mounted");
    // Request a callback roughly every 1000 ms; the OS can delay it.
    const intervalId = setInterval(() => setSeconds((current) => current + 1), 1000);
    // Cleanup: runs when Timer is removed
    return () => {
      clearInterval(intervalId);
      console.log("Timer unmounted");
    };
  }, []);

  return <Text>Seconds: {seconds}</Text>;
}

export default function App() {
  const [visible, setVisible] = useState(true);
  const [appState, setAppState] = useState(AppState.currentState);

  useEffect(() => {
    // Listen for the whole app going active or to the background
    const subscription = AppState.addEventListener("change", (nextAppState) => {
      setAppState(nextAppState);
      console.log("App state:", nextAppState);
    });
    return () => subscription.remove();
  }, []);

  return (
    <View style={{ flex: 1, padding: 24, paddingTop: 60, gap: 12 }}>
      <Text>App state: {appState}</Text>
      {visible && <Timer />}
      <Button
        title={visible ? "Hide timer" : "Show timer"}
        onPress={() => setVisible((currentVisible) => !currentVisible)}
      />
    </View>
  );
}

Read in three parts

  • Timer: local count, interval, cleanup.
  • App: visible and appState values.
  • UI: conditionally include Timer and pass a press callback.
