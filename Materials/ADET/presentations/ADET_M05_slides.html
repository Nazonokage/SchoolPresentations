Guided program

Complete model: make history visible

import { useState } from "react";
import { View, Text, Button } from "react-native";

export default function App() {
  // A teaching model of a stack; this is NOT Expo Router.
  const [routes, setRoutes] = useState<string[]>(["home"]);
  const currentRoute = routes[routes.length - 1];
  const officeName = currentRoute === "library" ? "Library — Open 8 AM" : "Office not found";
  function pushOffice(id: string) {
    setRoutes((currentRoutes) => [...currentRoutes, id]);
  }
  function goBack() {
    // Keep the home route when there is no previous screen.
    setRoutes((currentRoutes) => currentRoutes.length > 1 ? currentRoutes.slice(0, -1) : currentRoutes);
  }
  return (
    <View style={{ flex: 1, padding: 24, paddingTop: 60, gap: 16 }}>
      <Text>Navigation paper-model companion</Text>
      <Text>Stack: {routes.join(" → ")}</Text>
      {currentRoute === "home" ? (
        <View style={{ gap: 12 }}>
          <Button title="Visit library" onPress={() => pushOffice("library")} />
          <Button title="Try unknown office" onPress={() => pushOffice("unknown")} />
        </View>
      ) : <Text>{officeName}</Text>}
      <Button title="Back" disabled={routes.length === 1} onPress={goBack} />
    </View>
  );
}

What this models

  • An array stores the destinations.
  • Spread appends an ID.
  • slice removes the last entry.
  • A guard keeps Home at the bottom.

It has no native routing, external deep links or persisted history.

Router file 3 of 3

Detail checks the ID before displaying it

import { View, Text, Button } from "react-native";
import { Stack, router, useLocalSearchParams } from "expo-router";

const offices: Record<string, { title: string; hours: string }> = {
  library: { title: "Library", hours: "Open 8 AM" },
};

export default function OfficeScreen() {
  const parameters = useLocalSearchParams<{ id?: string | string[] }>();
  // Normalize, then check existence. Types alone do not validate an incoming URL.
  const officeId = Array.isArray(parameters.id) ? parameters.id[0] : parameters.id;
  const office = officeId && Object.hasOwn(offices, officeId) ? offices[officeId] : undefined;
  return (
    <View style={{ flex: 1, padding: 24, gap: 16 }}>
      <Stack.Screen options={{ title: office?.title ?? "Missing office" }} />
      <Text>{office ? `${office.title} — ${office.hours}` : "Office not found"}</Text>
      <Button title={router.canGoBack() ? "Back" : "Home"}
        onPress={() => router.canGoBack() ? router.back() : router.replace("/")} />
    </View>
  );
}

Trace the lookup

  • Normalize a possible array parameter.
  • Check that offices owns the key.
  • Render the record or the missing message.
  • Use Back when history exists; otherwise offer Home.
Main lesson

Links and guards have boundaries

Deep link

A URL can open a destination directly. In-app navigation can use compatible Expo Go; a custom installed scheme requires a build containing that native configuration.

Guard ≠ authorization

A redirect helps users navigate. The server still decides whether a request may access protected data.

Keep passwords and tokens out of routes.

Real-device links and navigation have not been tested here. Bundle generation alone does not establish their behavior.

Main lesson

Parang room number ang route

Analogy

Ang ID ay room number, hindi ang buong opisina. History ang dinaanan mo para makabalik.

Kapag mali ang number, sabihin na hindi nahanap—huwag magpakita ng ibang opisina.

Troubleshoot

  • Old App.tsx appears: inspect main.
  • Unmatched route: inspect the file tree.
  • Unknown ID crashes: validate the lookup.
  • No history: offer a Home fallback.
