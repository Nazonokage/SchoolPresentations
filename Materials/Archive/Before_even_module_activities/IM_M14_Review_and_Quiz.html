Recap · 1

UML (Unified Modeling Language)

A standard visual language used to create blueprints for software systems. It is divided into Structural (static) and Behavioral (dynamic) diagrams.

DiagramWhat it shows
Use CaseFunctional requirements and actors
ClassStatic structure, attributes and methods
SequenceMessage passing over time
State MachineStates and transitions of an object
ActivityFlow of control and processes
ComponentPhysical structure of the system
DeploymentPhysical hardware and software mapping

Recap · 2

Relational model, keys and indexing

Relational database model

Organizes data into tables (relations) of rows (records) and columns (attributes), linked by keys.

Primary key

Uniquely identifies a record.

Foreign key

Links to a primary key in another table to establish relationships.

Indexing

A data structure (like a book’s index) that speeds up data retrieval.

Recap · 3

Normalization

The process of organizing data to minimize redundancy and dependency.

Normal formRule
1NFAtomic values, unique rows
2NFNo partial dependencies (rely on the whole primary key)
3NFNo transitive dependencies (non-key columns cannot depend on other non-key columns)
BCNFA stricter version of 3NF

Answer key · 1

Questions 1 to 5

1. What is UML?

Unified Modeling Language is a general-purpose, standard visual modeling language used to specify, visualize, construct, and document the artifacts of software systems.

2. What is a use case diagram?

A behavioral UML diagram that represents the functional requirements of a system, illustrating the interactions between external actors and the system’s use cases.

3. What is a class diagram?

A structural UML diagram that represents the static structure of a system, showing its classes, attributes, methods, and the relationships between them.

4. What is a sequence diagram?

A behavioral UML diagram that shows how objects interact with each other over time, focusing on the sequence of messages passed between them.

5. What is a state machine diagram?

A behavioral UML diagram that illustrates the dynamic behavior of a single object, showing the different states it can be in and the events that trigger transitions between those states.

Answer key · 2

Questions 6 to 10

6. What is an activity diagram?

A behavioral UML diagram that models the workflow or flow of control within a system, representing the steps of a process.

7. What is a component diagram?

A structural UML diagram that represents the physical organization of a software system, showing how components (modular parts) are wired together.

8. What is a deployment diagram?

A structural UML diagram that visualizes the physical deployment of software artifacts onto hardware nodes (like servers or devices).

9. What is a relational database model?

A database model that organizes data into one or more tables (relations) of rows (records) and columns (attributes), where relationships are established using common keys.

10. What are the features of a good relational database design?

Minimal data redundancy, high data integrity (accuracy and consistency), scalability, efficient performance, and clear, logical table structures using primary and foreign keys.

Answer key · 3

Questions 11 to 15

11. What are the various normal forms from the first normal form through the Boyce-Codd normal form?

1NF: atomic values, unique rows. 2NF: 1NF + no partial dependencies. 3NF: 2NF + no transitive dependencies. BCNF: 3NF + every determinant is a candidate key.

12. What is normalization?

The process of organizing data in a database by dividing larger tables into smaller ones and linking them via relationships, to minimize data redundancy and improve data integrity.

13. What is a primary key?

A specific column (or set of columns) in a table that uniquely identifies every row in that table.

14. What is a foreign key?

A column (or set of columns) in one table that references the primary key of another table, creating a link between the two tables to enforce referential integrity.

15. What is indexing?

A database performance technique that creates a data structure (an index) on one or more columns to speed up the retrieval of rows, similar to an index at the back of a book.
