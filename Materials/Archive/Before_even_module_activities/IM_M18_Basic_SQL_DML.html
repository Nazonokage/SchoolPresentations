Main lesson · 1

What is DML?

Data Manipulation Language (DML) is a subset of SQL commands used to manage and manipulate the data within existing database objects. DML does not change the structure of the database; it only changes the rows of data.

SELECT

Retrieves data from one or more tables.

INSERT

Adds new records into a table.

UPDATE

Modifies existing records in a table.

DELETE

Removes records from a table.

Modern update, UPSERT (Merge): INSERT ... ON CONFLICT DO UPDATE (PostgreSQL) or INSERT ... ON DUPLICATE KEY UPDATE (MySQL) inserts a new row, but if the primary key already exists it updates that row instead of throwing an error.

Main lesson · 3A

INSERT (Create) and UPDATE (Modify)

INSERT adds new rows. UPDATE changes existing data: always use a WHERE clause unless you intend to update every row.

INSERT (SQL)
-- Syntax
INSERT INTO table_name (column1, column2, column3)
VALUES ('value1', 'value2', 'value3');

-- Example: add a new customer
INSERT INTO customers (name, email)
VALUES ('Ilse Varga', 'ilse@example.com');
UPDATE (SQL)
-- Syntax (always use a WHERE clause!)
UPDATE table_name
SET column1 = 'new_value1', column2 = 'new_value2'
WHERE some_column = some_value;

-- Example: change a customer's email
UPDATE customers
SET email = 'ivarga@example.com'
WHERE name = 'Ilse Varga';

Main lesson · 3B

DELETE (Remove) and soft deletes

DELETE removes rows. Always use a WHERE clause to prevent deleting the whole table’s data.

DELETE (SQL)
-- Syntax (always use a WHERE clause!)
DELETE FROM table_name
WHERE some_column = some_value;

-- Example: remove a customer
DELETE FROM customers
WHERE name = 'Ilse Varga';
Soft delete (SQL)
-- Instead of a hard delete:
DELETE FROM users WHERE id = 1;

-- We do a soft delete:
UPDATE users
SET deleted_at = CURRENT_TIMESTAMP
WHERE id = 1;

Best practice: a hard DELETE destroys history and can break foreign keys. Use a soft delete with an is_deleted or deleted_at column. The data stays for auditing and is easy to recover.

Analogy

The spreadsheet

  • INSERT: adding a new row at the bottom of your sheet.
  • SELECT: using the filter to show only rows where Department is “IT”.
  • UPDATE: clicking a cell and typing a new value over the old one.
  • DELETE: highlighting a row, right-clicking and choosing “Delete Row”.

Real-world use case

E-commerce inventory management

An online store uses DML constantly.

  1. A customer buys a shirt: an INSERT creates a new order record.
  2. An UPDATE decreases quantity_in_stock by 1.
  3. A customer cancels: instead of a DELETE (which might ruin financial reporting), an UPDATE sets the order status to Cancelled (soft delete).

Security: SQL injection

In a web application (PHP, Python), don’t build INSERT or UPDATE queries with string concatenation. Malicious users can inject SQL code. Always use Prepared Statements (parameterized queries), which separate the SQL code from the user data.

FAQs

Common questions

DELETE without a WHERE clause?

It deletes every single row in the table, leaving an empty table structure. Be extremely careful and back up data before running queries on production databases.

What does MERGE do?

The MERGE statement (also UPSERT) inserts new data or updates existing data based on a condition. Very useful for synchronizing two tables.

DELETE vs. TRUNCATE?

DELETE is DML: it removes rows one by one, can be filtered with WHERE, and can be rolled back (in a transaction). TRUNCATE is DDL: it removes all rows at once, can’t be filtered, and usually can’t be rolled back.

Manage a products table

You manage a database for an electronics store.

  1. Retrieve all products with a price greater than 2.00.
  2. Increase the price of all products by 10%.
  3. Delete all products with a quantity less than 100.
  4. Retrieve all products supplied by ‘A’, ordered by product_name ascending.
  5. Retrieve the average price of all products.
Solutions (SQL)
-- 1. Retrieve products > 2.00
SELECT * FROM products WHERE price > 2.00;

-- 2. Increase price by 10%
UPDATE products SET price = price * 1.1;

-- 3. Delete products with quantity < 100
DELETE FROM products WHERE quantity < 100;

-- 4. Retrieve Supplier A, ordered by name
SELECT * FROM products
WHERE supplier = 'A'
ORDER BY product_name ASC;

-- 5. Average price
SELECT AVG(price) FROM products;

Key quotes

Key definitions to remember

DML

SQL commands that manage the data within existing database objects, without changing the structure.

CRUD

Create (INSERT), Read (SELECT), Update (UPDATE), Delete (DELETE).

Soft delete

Marking a row inactive with a column such as deleted_at instead of physically removing it.

Prepared statements

Parameterized queries that separate SQL code from user data.

Recap

Manipulate with care

DML manipulates the actual data using CRUD operations. Comparison and logical operators filter exactly which rows are affected.

Always exercise caution with UPDATE and DELETE to avoid accidental data loss.
