Recap · 1

Information systems (IS)

A combination of hardware, software, data, procedures, and people working together to process and distribute information.

Benefits

Improved efficiency, better decision-making, cost savings.

Drawbacks

High implementation cost, technical difficulties, vulnerability to cyber-attacks.

Recap · 2

System Development Life Cycle (SDLC)

Building an IS typically follows these phases: Planning/Analysis, Design, Implementation, and Maintenance.

Feasibility studies

Determine if a project is financially and technically viable.

Prototyping

Creates a working model for early user feedback.

Agile

A modern development method focusing on flexible, incremental releases rather than rigid, linear progress.

Recap · 3

Databases

A database is an organized collection of data.

DBMS

The software (like MySQL) used to manage, retrieve and manipulate the data.

Drivers and connectors

Software components (like ODBC or JDBC) that let applications communicate with the database.

NoSQL databases

Non-relational databases that store data as key-value pairs, documents (like MongoDB) or graphs. Great for unstructured data.

Time-series databases

Optimized for data tracked over time (timestamps).
