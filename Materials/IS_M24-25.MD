## B. Project Mechanics & Scope

You are required to select a real-world problem that can be solved using a relational database. The problem should have clear requirements and enough complexity to demonstrate your skills.

**Modern Project Examples:**
*   **E-Commerce Platform:** Build a database to handle order tracking, inventory management, and customer reviews.
*   **Social Media App:** Design a backend for user profiles, posts, comments, and follower relationships.
*   **Business Intelligence Data Warehouse:** Create a schema to store and analyze sales data from multiple branches (using a Star Schema).
*   **Library Management System:** Track books, authors, borrowers, loans, and late fees.
*   **Personal Finance Tracker (Modern addition):** A system to track expenses, income, budgets, and generate category summaries.

## C. Deliverables & Project Phases

Your project must include the following components. Treat this as a professional portfolio piece. 

### 1. Problem Statement & Background (10%)
*   Write a clear statement of the problem.
*   Provide relevant background information.
*   Explain the requirements and complexity of the problem. Why is this database necessary?

### 2. Data Analysis & Preprocessing Report (20%)
*   Identify the source of your data (e.g., a public dataset from Kaggle, generated sample data, or a CSV file).
*   Document your **data cleaning and preprocessing steps**. 
*   *Modern Update:* You can use tools like Excel, Python (Pandas), or SQL itself to clean the data before importing it into your final tables. Document any challenges encountered (e.g., inconsistent date formats, duplicate records).

### 3. Schema Design & Query Implementation (25%)
*   **ERD (Entity-Relationship Diagram):** Create a visual diagram of your schema. (Pro-tip: Use Mermaid.js or dbdiagram.io to generate this from code).
*   **Schema Definition:** Provide the SQL `CREATE TABLE` statements.
*   **Queries:** Include a detailed description of the queries used to retrieve and manipulate data. You must demonstrate:
    *   `SELECT`, `INSERT`, `UPDATE`, `DELETE` (CRUD operations)
    *   `JOIN`s (combining tables)
    *   Aggregation (`GROUP BY`, `SUM`, `COUNT`)
    *   At least one complex query (Subquery or CTE).

### 4. Final Report & Performance Evaluation (30%)
*   Describe how the solution meets the original requirements.
*   **Performance Metrics:** Demonstrate that you understand optimization. Use `EXPLAIN` or `EXPLAIN ANALYZE` on your queries. Show how adding an **Index** improved the performance of a search query.
*   Discuss any challenges encountered and how you solved them.

### 5. Live Demonstration / Presentation (15%)
*   A brief (5-10 minute) presentation to the class (or a recorded video).
*   Demonstrate your running database. Show the schema, run a few complex queries, and explain your design decisions.

To make your project stand out and align with industry standards, consider using these modern tools:

| :--- | :--- |
