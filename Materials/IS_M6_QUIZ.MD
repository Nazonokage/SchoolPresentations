## Part 1: Lesson Recap & Review

Before taking the quiz, quickly review these key concepts from the recent modules:

*   **Information Systems (IS):** A combination of hardware, software, data, procedures, and people working together to process and distribute information. 
    *   *Benefits:* Improved efficiency, better decision-making, cost savings.
    *   *Drawbacks:* High implementation cost, technical difficulties, vulnerability to cyber-attacks.
*   **System Development Life Cycle (SDLC):** The process of building an IS typically follows these phases: **Planning/Analysis, Design, Implementation, and Maintenance.** 
    *   *Feasibility Studies* determine if a project is financially and technically viable.
    *   *Prototyping* creates a working model for early user feedback.
    *   *Agile* is a modern development method focusing on flexible, incremental releases rather than rigid, linear progress.
*   **Databases:** Organized collections of data. 
    *   **DBMS (Database Management System):** The software (like MySQL) used to manage, retrieve, and manipulate the data.
    *   **Database Drivers/Connectors:** Software components (like ODBC or JDBC) that allow applications to communicate with the database.
    *   **NoSQL Databases:** Non-relational databases that store data in formats like key-value pairs, documents (like MongoDB), or graphs. They are great for unstructured data.
    *   **Time-Series Databases:** Specifically optimized to handle data tracked over time (timestamps).

## Part 3: Answer Key

1.  **a** (A database driver translates application requests into commands the DBMS understands.)
2.  **a** (Standard SDLC phases include Planning, Analysis, Design, Implementation, and Maintenance.)
3.  **b** (NoSQL databases are non-relational and handle flexible data formats.)
4.  **a** (MySQL is a classic example of a relational DBMS. *Note: MongoDB (b) is also valid database software, but MySQL is typically the standard expected answer in introductory courses.*)
5.  **a** (Efficiency is a major benefit; increased cost and complexity are disadvantages.)
6.  **b** (Feasibility studies evaluate if a project is financially, technically, and operationally viable.)
7.  **c** (Drivers are often specific to the DBMS API, while connectors like ODBC can bridge multiple database types.)
8.  **c** (Time-series databases are specialized for IoT, stock ticks, and other time-stamped data.)
9.  **b** (*Note: Option 'c' is also technically a disadvantage, but 'b'—high cost—is the most emphasized disadvantage in standard texts.*)
10. **b** (Prototypes are built to show users a working model early in development.)
11. **d** (Data flow analysis tracks how data moves through an organization/systems.)
12. **a** (Agile focuses on iterative delivery and adapting to change.)
13. **c** (UI design focuses on usability and meeting user needs.)
14. **c** (QA ensures the system works as required without bugs.)
15. **c** (Backups are the safety net to restore data after an outage or disaster.)
