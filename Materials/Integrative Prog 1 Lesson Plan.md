# Integrative Programming & Technologies 1 (IPT 1)

**Primary Stack:** Python + PHP (XAMPP) + Bootstrap 5

This repository contains the complete 25-module lesson plan, activities, and resources for **Integrative Programming & Technologies 1**.

---

## Course Description

This course covers the integration of applications and systems. It focuses on:

- Scripting languages and their role in integration
- Data mapping and exchange (XML & JSON)
- Inter-system communication
- Web services and REST APIs
- Middleware concepts
- Security practices
- Practical integration using databases and APIs
- Building simple but functional integrated web applications

Students will learn how to make different systems work together reliably using **Python**, **PHP**, and **Bootstrap**.

---

## Learning Outcomes

By the end of the course, students should be able to:

- Explain system integration concepts, architectures, and challenges
- Use scripting, design patterns, interfaces, and inheritance for integrative coding
- Perform data mapping and exchange using XML and JSON
- Implement inter-system communication (sockets, messaging, web services, REST)
- Apply middleware and basic API security concepts
- Integrate applications with databases
- Build a simple but complete integrated system with a responsive frontend

## 25-Module Lesson Plan

### Part 1: Foundations
1. Introduction to Integrative Programming & Technologies  
2. Programming Languages & Paradigms Overview  
3. Scripting Languages Fundamentals (Python & PHP)  
4. System Integration Concepts & Models  
5. Architectures for Integrating Systems  
6. Distributed Processing Technologies (DCOM, CORBA, RMI – overview)

### Part 2: Communication & Data Exchange
7. Socket Programming & Low-Level Communication  
8. Messaging & Queuing Services  
9. Data Mapping & Exchange – XML Basics  
10. XML Schema Definition (DTD & XSD)  
11. XML Processing & Transformation (DOM, SAX, XPath, XSLT)  
12. JSON & Modern Data Exchange  

### Part 3: Integrative Coding & Middleware
13. Integrative Coding – Design Patterns  
14. Interfaces, Inheritance & Code Reuse  
15. Version Control for Integrative Projects (Git)  
16. Middleware Concepts  
17. Service-Oriented Architecture (SOA)  

### Part 4: Web Services, Security & Databases
18. Web Services Fundamentals (SOAP vs REST)  
19. REST APIs in Depth  
20. API Security Basics  
21. Database Integration (MySQL via XAMPP + Python/PHP)  
22. Testing, QA & Usability in Integrated Systems  

### Part 5: Frontend, Modern Tools & Capstone
23. Bootstrap Fundamentals & Responsive Design  
24. Web Frameworks & Modern Integration Tools (Python/PHP + Bootstrap)  
25. Capstone Project & Course Synthesis

## Capstone Project (Module 25)

Students will design and build a simple integrated system that includes:

- Python scripts (data processing / automation)
- PHP web service or REST API
- MySQL database (via XAMPP)
- Data exchange using JSON and/or XML
- Responsive frontend using **Bootstrap 5**
- Basic authentication / security
- Proper documentation and Git usage

---

## Teaching Tips

- Introduce Bootstrap only in the later modules (Module 23) so students first focus on the integration logic.
- Encourage the use of Bootstrap components (navbar, cards, forms, tables, modals) to make projects look professional.
- Keep laboratory activities highly hands-on.
- Maintain consistency with the **Python + PHP + Bootstrap** stack.
