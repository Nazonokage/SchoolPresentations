Recap · Module 10
Content Distribution & CMS

What is a CMS?

A Content Management System is software that lets users create, manage, and publish digital content without requiring deep coding knowledge. Examples: WordPress, Wix, Shopify, Joomla, Blogger.

Key CMS Features

  • Content creation & editing (WYSIWYG)
  • User role management (admin, editor, viewer)
  • Template & theme systems
  • Plugin / extension marketplace
  • SEO & media management tools

Content Distribution Platforms

  • Blogging: WordPress, Blogger, Medium
  • E-commerce: Shopify, WooCommerce
  • Portfolio / Landing: Wix, Squarespace
  • Wiki / Docs: Confluence, Notion

Why CMS Matters

Separates content from presentation — writers work independently from developers. Reduces time-to-publish and enables non-technical teams to manage websites.

Recap · Module 10
The 3 Types of Media (Simple Version)

💡 Easiest way to remember it: ask yourself — "Did I pay for this, do I own it, or did I earn it?"

🟡 Paid Media

In simple terms: you pay money so people see your content.

Like renting a billboard — instant reach, but the moment you stop paying, it disappears.

Examples: Meta Ads, Google Ads, Amazon Ads, LinkedIn Ads

🟣 Owned Media

In simple terms: channels you fully control — no rent, no landlord.

Like owning a house — it's yours forever and you decide what goes in it.

Examples: Website/Blog, Email List, Social Profiles, YouTube Channel, Podcast

🟢 Earned Media

In simple terms: other people talk about you for free, because they want to.

Like a friend recommending a restaurant — you didn't pay for it, but people trust it more.

Examples: Reviews, Press Coverage, Shares, Backlinks, Influencer Mentions

🪑 The Three-Legged Stool

A strategy only stands strong when all three legs are there: Paid = Amplification (boosts reach) · Owned = Foundation (your home base) · Earned = Validation (proof people trust you). Relying on just one leg makes the whole thing wobble.

Multi-Platform & JavaScript

Cross-Platform vs Platform-Agnostic

Cross-Platform: Software runs on multiple hardware/OS environments (Windows, macOS, Android, iOS).

Platform-Agnostic: Code doesn't rely on any specific OS or hardware — "write once, run anywhere."

6 Cross-Platform Approaches

  • Web-Based Apps — HTML/CSS/JS in browser
  • Hybrid Mobile — JS wrapped in native container
  • Native Cross-Platform — React Native, Flutter
  • PWAs — installable web apps
  • Desktop — Electron (Windows/macOS/Linux)
  • Game Engines — Unity, Unreal

Recap · Module 14
NoSQL Databases & JS Setup

What is NoSQL?

A non-relational database that stores data without a rigid predefined schema. Ideal for unstructured/semi-structured data at scale.

FeatureMySQLNoSQL
SchemaFixed tablesFlexible
ScalingVerticalHorizontal
DataStructured onlyAny shape

5 NoSQL Traits

  • Schema Flexibility — no predefined structure
  • Horizontal Scaling — distributes across nodes
  • High Availability — auto replication/failover
  • Diverse Data Models — Key-Value, Doc, Graph…
  • Eventual Consistency — async replication

JavaScript Setup (VS Code + Node.js)

1

Install Node.js

Download from nodejs.org

2

Open VS Code

Launch editor, open project folder

3

Init project

Run npm init → package.json

4

Write logic

Create .js files, use node file.js

Key Analogy

MySQL = a spreadsheet with locked column headers. NoSQL = a notebook where each page can look completely different — some have tables, some have paragraphs, some have photos.

Stateless Architecture & System Drivers

Stateless Architecture

Each request is independent — the server retains no session memory of prior requests.

Key Rule:

Client must send all context (tokens, session IDs) with every single request.

💡 In simple terms: like ordering at a fast-food counter — the cashier forgets you the second you walk away, so you must repeat your whole order every single time.

Benefits: No server-side sessions · Seamless scalability · Optimized load balancing · Reduced server overhead
