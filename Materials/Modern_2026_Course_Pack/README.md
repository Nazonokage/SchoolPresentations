## Intended final deliverables

- 17 complete ADET Markdown lessons and 17 complete EDP Markdown lessons.
- Setup instructions, full runnable starter files, expected results, and troubleshooting.
- Per-module learning targets, plain-language explanations, Taglish analogies, guided activities, and independent modifications.
- Course-specific projects, grading rubrics, teacher demonstration notes, and validation records.
- A consistent dependency baseline and an explicit label for simulations, optional services, and native-device requirements.

The `_draft` directory holds unfinished authoring work begun before the research-first request. It is not teaching material and has not been tested. No generated lessons from that draft should be treated as final.
