# Offline recorded activities

Even-numbered presentations retain their original lessons, examples, visuals and recaps. Only their assessment sections are replaced by topic-related XAMPP/phpMyAdmin practical activities, 20 points each. Recorded means instructor-recorded grades supported by saved work; no video recording is required.

Install and test XAMPP before class. Distribute the complete Offline_Activities and Presentations folders via USB. Internet is not required during activities. Use fictional data. Each module starts with a new database. Starter SQL is supplied only for modules 14, 18, 20 and 22; students build the others themselves.

- [Module 4: Create a database and choose data types](M04/Instructions.md)

- [Module 8: Implement entities and relationships](M08/Instructions.md)
