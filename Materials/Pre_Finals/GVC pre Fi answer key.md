## IV. Coding Problem (5 pts)
**56.**
```html
<dl>
  <dt>Name</dt>
  <dd>Ana Cruz</dd>
  <dt>Course</dt>
  <dd>BSIT</dd>
</dl>
<ul data-student-id="2024001">
  <li>Math</li>
  <li>Programming</li>
  <li>Graphics</li>
</ul>
```

| Pt | Criterion |
|---|---|
| 1 | `<dl>` opens and closes properly, wrapping the `<dt>`/`<dd>` pairs |
| 2 | Both pairs correct: `<dt>Name</dt><dd>Ana Cruz</dd>` and `<dt>Course</dt><dd>BSIT</dd>`, in order |
| 3 | `<ul>` opens and closes properly and is placed after the `<dl>` |
| 4 | Exactly three `<li>` elements with the correct text, in order |
| 5 | `data-student-id="2024001"` placed on the `<ul>` |
