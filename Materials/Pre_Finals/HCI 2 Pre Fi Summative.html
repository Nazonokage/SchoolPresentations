Introduction to Augmented Reality

🧠 3 Core Features of AR
  • Combination of real and virtual worlds
  • Real-time interaction between user and digital
  • Accurate 3D registration of virtual & real objects
⚔️ AR vs VR vs MR

AR enhances reality by adding layers on top.
VR replaces reality entirely (headset required).
MR lets digital and physical objects interact.

🔧 The 6 Types of AR
Marker-BasedUses image recognition / specific QR patterns
MarkerlessUses sensors (GPS/Gyros) instead of images
Projection-BasedImmersive light projected on flat surfaces
Location-BasedTriggered by GPS (e.g., Pokémon GO)
OverlayReplaces physical view with enhanced 3D image
Contour-BasedOutlines real objects (safe nighttime driving)

AR Hardware & Display Types

MEMS → 6DoF
  • MEMS = tiny embedded sensors: cameras, accelerometers, GPS, solid-state compasses
  • Together they enable 6 Degrees of Freedom (6DoF) tracking
  • Core hardware: Processor, Display, Sensors, Input devices
SLAM
  • Simultaneous Localization and Mapping
  • Used by Projection-Based & Contour-Based AR

Module 17 Review

CSS perspective Drill

CSS / JS — AR.html
/* parent sets the depth */
#div1 { perspective: 200px; }
/* child is tilted away */
#div2 { transform: rotateX(45deg); }

function changePersp(value) {
  document.getElementById('div1')
    .style.perspective = value + "px";
}
What it does
  • perspective = distance from the viewer's eye to the 3D plane
  • Low (45px) = very distorted / close
  • High (2000px) = nearly flat / far
  • rotateX(45deg) tilts the child; the parent's perspective sets how 3D it looks
Link to WebAR

AR engines compute viewer distance/angle and adjust the depth of virtual objects. CSS perspective is the browser-native version of that math.

Modules 19 & 20 Review

Python Text-to-Speech

gTTS (Google TTS)
  • Online only: Requires active internet.
  • Output: High-quality `.mp3` audio files.
  • Pros: Single end-to-end model, no local DB needed.
  • Cons: Flat prosody (due to L1/L2 loss functions), API rate limits.
  • Windows Playback: Requires `os.system("mpg321 output.mp3")`.
pyttsx3
  • Offline completely: Uses native OS engines.
  • Engines: sapi5 (Win), nsss (Mac), espeak (Linux).
  • Output: Real-time playback (no direct MP3).
  • Init: Uses a factory function `pyttsx3.init()` to return the engine reference.
  • Action: Call `engine.say()` then `engine.runAndWait()`.
⏩
The 6-Step gTTS Workflow

1. Install  •  2. Import  •  3. Input  •  4. Create gTTS()  •  5. Save  •  6. Play os.system()

pip, gTTS Parameters & pyttsx3 Script

pip
  • Python's package management system (NOT Python itself)
  • pip install gTTS
  • pip install pyttsx3
gTTS(text, lang, slow)
  • text = string to speak
  • lang = 'en', 'es', 'fr', 'de', 'hi', 'tl' (Filipino)
  • slow = False normal, True slower
  • Save: tts.save("output.mp3")
Python — pyttsx3 (offline)
import pyttsx3
engine = pyttsx3.init()
text = input("Enter the text you want to hear: ")
engine.say(text)
engine.runAndWait()
print("Finished speaking!")

The QR Code Bridge

When linking Google Forms to WebAR, the QR Code acts as the bridge. Users scan it within the form to launch the AR experience without installing apps.

Python — qrcode 
import qrcode

# 1. Create the QR code object
qr = qrcode.QRCode(
    version=1, 
    box_size=10, 
    border=4
)

# 2. Add URL data and make
qr.add_data("https://ar-link.com")
qr.make(fit=True)

# 3. Create image (color customizable)
img = qr.make_image(
    fill_color="black", 
    back_color="white"
)

# 4. Save to file
img.save("qr-code.png")

Module 23 Review

Map APIs & Spatial Intelligence

Geocoding Operations
📍 Geocoding

Converts a human-readable address into exact GPS coordinates (Lat/Lng).

🌐 Reverse Geocoding

Takes GPS coordinates and converts them back into a human-readable address.

Top Providers
  • Google Maps: Industry standard, broadest features.
  • Mapbox: Highly customizable vector maps (50k free views).
  • Foursquare: Best for venue data and analytics.
Embed & APIs

To embed a map without an API key, simply use an <iframe> tag. To locate the user dynamically in JS, use the browser's built-in navigator.geolocation API.

Code Showcase

Interactive Map Prototype

HTML / JS — map.html 
<button onclick="map_data()">Map it</button>
<p id="demo"></p>

<script>
function map_data() {
    // Ask the user for a location string
    let x = prompt("Enter location");
    
    // Check conditional logic
    if (x == "iloilo") {
        // Open new tab to map
        window.open("https://www.google.com/maps/place/Iloilo+City");
    } else {
        // Target paragraph and manipulate DOM
        document.getElementById("demo").innerHTML = 
            "404! Location not found.";
    }
}
</script>
Logic Breakdown

  • Event Listener: The onclick attribute on the button triggers the JS function immediately.
  • Input: prompt() is used to capture a string from the user.
  • Routing: The if/else checks the string. If matched, it uses window.open().
  • DOM Manipulation: If unmatched, it uses document.getElementById().innerHTML to display an error text natively on the page.
