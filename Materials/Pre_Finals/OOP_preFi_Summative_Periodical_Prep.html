Quick Recap 1

static, main() and final

static field

  • ONE shared copy for all objects
  • Access it with ClassName.field
  • Ticket.nextId++ affects every ticket

static context rule

  • A static method has no object
  • It cannot use instance fields or methods
  • Result: Compile Error

Why main() is static

  • The JVM calls it before any object exists
  • No new needed to start the program

final

  • Value set once, then locked
  • Reassigning it = Compile Error
  • Not the same as static or private
Quick Recap 2

this(), super() and the Pillars

this() vs super()

  • this(...) calls another constructor in the SAME class
  • super(...) calls the PARENT constructor
  • Both must be the first line

Overriding vs Overloading

  • Overriding: same signature, subclass redefines (runtime)
  • Overloading: same name, different parameters (compile-time)

Abstract class vs Interface

  • extends one class, implements many interfaces
  • Neither can be created with new
  • Abstract methods have no body

The 4 Pillars

  • Encapsulation
  • Inheritance
  • Abstraction
  • Polymorphism
Quick Recap 3

Arrays and Pass-by-Value

array.length

  • A field, no parentheses
  • Valid indexes: 0 to length - 1

Out of bounds

  • arr[arr.length] or arr[-1]
  • Runtime: ArrayIndexOutOfBoundsException
  • The compiler does NOT catch it

Primitives

  • A copy of the value is passed
  • modify(a) cannot change the caller's a

Objects

  • The reference is passed by value (copied)
  • Java is always pass-by-value
