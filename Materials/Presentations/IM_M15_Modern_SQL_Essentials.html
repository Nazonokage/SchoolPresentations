Main lesson · 1

Basic concepts of SQL

SQL (Structured Query Language) is the standard programming language for managing and manipulating relational databases.

Tables

The basic building block. Data is organized into rows (records) and columns (fields).

Schema

The structure of the database: tables, fields, relationships and constraints.

Indexes

Data structures that speed up data retrieval.

Primary key

A unique identifier for each record in a table (e.g., CustomerID).

Foreign key

A field that references the primary key of another table, creating a link.

Main lesson · 2

DDL, DML, DQL (and beyond)

SQL commands were originally grouped into three categories. Modern database management also includes DCL and TCL.

CategoryPurposeCommon commands
DDL (Data Definition)Defines the structure of the database.CREATE, ALTER, DROP, TRUNCATE
DML (Data Manipulation)Manages the data within the tables.INSERT, UPDATE, DELETE
DQL (Data Query)Retrieves data from the database.SELECT
DCL (Data Control)Manages access and permissions.GRANT, REVOKE
TCL (Transaction Control)Manages transactions.COMMIT, ROLLBACK, SAVEPOINT

Modern best practice

DDL as code

In modern DevOps, DDL is no longer just typed into a console. Teams use Schema-as-Code tools (Flyway, Liquibase, Prisma Migrate) to version-control their CREATE TABLE and ALTER TABLE statements.

Database changes are tracked and deployed automatically through CI/CD pipelines.

Main lesson · 2B

SQL query execution order

You write SQL starting with SELECT, but the engine executes the clauses in a different order to optimize performance.

Why it matters

WHERE filters rows before GROUP BY forms groups. HAVING then filters the groups.

Main lesson · 4

SQL constraints: enforcing data integrity

Rules applied to columns to ensure accuracy and reliability. Modern practice: name your constraints explicitly, e.g., CONSTRAINT chk_positive_price CHECK (price >= 0), instead of relying on system-generated names that vary across environments.

  • NOT NULL: a column cannot have a NULL value.
  • UNIQUE: all values in a column are different.
  • PRIMARY KEY: uniquely identifies each row. A table can have only one.
  • FOREIGN KEY: links to a primary key in another table, enforcing referential integrity.
  • CHECK: values meet a condition (e.g., price > 0).
  • DEFAULT: sets a value if none is provided.

Analogy

Spreadsheet vs. database

  • Table: a single sheet in a spreadsheet.
  • Row: a single row of data.
  • Primary key: a unique ID column you never duplicate.
  • Foreign key: a formula that looks up a value in another sheet.
  • Index: a filter or pivot table that finds data instantly without scrolling through thousands of rows.

Real-world use case

AI-powered search

A modern e-commerce platform uses a VECTOR column to store product embeddings.

When a user searches “comfortable running shoes”, the database runs a semantic similarity search on the vectors, returning products that are conceptually similar even if the exact keywords don’t match.

FAQs

Common questions

DDL vs. DML?

DDL defines structure (e.g., CREATE TABLE). DML manages the data inside the tables (INSERT, UPDATE, DELETE).

What is a primary key?

A column or set of columns that uniquely identifies every record in a table. Values must be unique and cannot be NULL.

What is a foreign key?

A column that references the primary key of another table. It creates a relationship and enforces referential integrity.

Why are vector types important?

They store high-dimensional embeddings used by AI models for semantic search, recommendation systems and RAG applications.

Guided drill

Build a modern Employee table

Create an Employee table with appropriate data types and constraints, then perform basic DML operations.

DDL and INSERT (SQL)
-- 1. DDL: Create the table with constraints
CREATE TABLE Employee (
    id INT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    age INT CHECK (age >= 18),
    gender VARCHAR(20),
    salary DECIMAL(10, 2) DEFAULT 30000.00,
    skills JSON, -- Modern JSON type
    embedding VECTOR(1536) -- Modern AI Vector type
);

-- 2. DML: Insert data
INSERT INTO Employee
    (id, name, age, gender, salary, skills)
VALUES (1, 'Marek Voss', 30, 'male', 50000,
        '["SQL", "Python"]');

INSERT INTO Employee
    (id, name, age, gender, salary)
VALUES (2, 'Tamsin Rook', 25, 'female', 40000);
SELECT, UPDATE, DELETE (SQL)
-- 3. DQL: Retrieve data
-- Find employees earning more than 45000
SELECT name, salary FROM Employee WHERE salary > 45000;

-- 4. DML: Update data
-- Give all employees a 10% raise
UPDATE Employee SET salary = salary * 1.1;

-- 5. DML: Delete data
-- Remove an employee
DELETE FROM Employee WHERE id = 2;
