Main lesson · 1

The SELECT statement

Data Query Language (DQL) is a subset of SQL used to retrieve data. The primary command is SELECT, which selects, filters, sorts and retrieves specific data from one or more tables.

SELECT basics (SQL)
-- Retrieve all columns from a table
SELECT * FROM employees;

-- Retrieve specific columns from a table
SELECT first_name, last_name FROM employees;

-- Filter with WHERE: salary greater than 50,000
SELECT * FROM employees WHERE salary > 50000;

Aggregate functions

Aggregate functions perform a calculation on a set of values and return a single value. They are essential for summarizing data.

FunctionDescriptionExample
SUM()Sum of all values in a column.SELECT SUM(salary) FROM employees;
COUNT()Number of rows in a column.SELECT COUNT(*) FROM employees;
AVG()Average of all values in a column.SELECT AVG(salary) FROM employees;
MIN()Minimum value in a column.SELECT MIN(salary) FROM employees;
MAX()Maximum value in a column.SELECT MAX(salary) FROM employees;
COUNT(DISTINCT)Number of unique non-null values.SELECT COUNT(DISTINCT department) FROM employees;

Grouping and sorting

GROUP BY groups rows with the same values into summary rows. ORDER BY sorts the result in ascending (ASC) or descending (DESC) order.

GROUP BY, ORDER BY, HAVING (SQL)
-- Total salary for each department
SELECT department, SUM(salary)
FROM employees
GROUP BY department;

-- Sort employees by salary, highest first
SELECT * FROM employees ORDER BY salary DESC;

-- HAVING filters the groups
SELECT department, SUM(salary)
FROM employees
GROUP BY department
HAVING SUM(salary) > 200000;

The missing link: HAVING

WHERE filters individual rows before grouping. To filter the groups (e.g., show only departments with a total salary above 200,000), use HAVING.

Modern update

How SQL actually executes

You start a query with SELECT, but the engine processes the clauses in a different logical order to optimize performance.

Why it matters

Since SELECT runs late, you can’t use a column alias defined in SELECT inside the WHERE clause.

Modern update

Window functions

GROUP BY collapses rows into one summary row. Window functions (the OVER() clause) perform aggregate calculations without losing the individual row details.

Window function (SQL)
-- Show each employee's row plus the total
-- salary of their department
SELECT first_name, department, salary,
       SUM(salary) OVER(PARTITION BY department)
         AS dept_total_salary
FROM employees;

What it does

Adds a column with the total salary of the employee’s department next to every employee’s own row.

Analogy

The supermarket receipt

  • SELECT *: looking at the entire receipt line by line.
  • WHERE: highlighting only items that cost more than $10.
  • GROUP BY: sorting items into categories (Produce, Dairy, Meat) to see where you spent most.
  • SUM / AVG: the total spent on dairy, or the average price of a meat item.
  • HAVING: after grouping, looking only at categories where you spent more than $50.

Real-world use case

AI-assisted data analysis (Text-to-SQL)

AI tools (ChatGPT, Copilot, BI tools) can generate DQL from natural language.

The request

A manager asks: “What was the average sales price per category in Q3?”

The query

SELECT category, AVG(price) FROM sales WHERE date BETWEEN '2023-07-01' AND '2023-09-30' GROUP BY category;

Understanding DQL is crucial for verifying that the AI generated the correct logic.

FAQs

Common questions

Aggregate vs. regular functions?

Aggregate functions work on a set of values and return one value (e.g., SUM). Scalar functions work on a single value and return a single value (e.g., UPPER('hello')).

Aggregates in a WHERE clause?

No. WHERE filters individual rows before aggregation. To filter on an aggregate result, use HAVING.

COUNT(*) vs. COUNT(column_name)?

COUNT(*) counts all rows, including rows with NULL. COUNT(column_name) counts only rows where that column is not NULL.

Hands-on exercise

Analyze sales data

A database sales has a table sales_data. Write queries for the business questions.

sales_idproduct_namecategorydatequantityprice
1Product AElectronics2022-01-0110100
2Product BClothes2022-01-02550
3Product CElectronics2022-01-0320150
4Product DBooks2022-01-041525
  1. How many total products were sold?
  2. How many transactions are recorded?
  3. What is the average price?
  4. What are the minimum and maximum prices?
  5. How many distinct categories are there?
  6. How many products were sold in each category?
  7. Total revenue (quantity × price) by category and date.
Solutions (SQL)
-- 1. Total products sold (Result: 50)
SELECT SUM(quantity) FROM sales_data;

-- 2. Total transactions (Result: 4)
SELECT COUNT(*) FROM sales_data;

-- 3. Average price (Result: 81.25)
SELECT AVG(price) FROM sales_data;

-- 4. Min and max price (Result: 25, 150)
SELECT MIN(price), MAX(price) FROM sales_data;

-- 5. Distinct categories (Result: 3)
SELECT COUNT(DISTINCT category) FROM sales_data;

-- 6. Products sold per category
SELECT category, SUM(quantity)
FROM sales_data
GROUP BY category;

-- 7. Revenue by category and date
SELECT category, date,
       SUM(quantity * price) AS total_sales
FROM sales_data
GROUP BY category, date;

Key definitions to remember

DQL

The subset of SQL used to retrieve data. Primary command: SELECT.

Aggregate function

Performs a calculation on a set of values and returns a single value.

HAVING

Filters the groups created by GROUP BY.

Window function

Aggregates with OVER() without collapsing individual rows.
