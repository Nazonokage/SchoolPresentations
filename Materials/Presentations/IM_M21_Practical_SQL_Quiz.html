Recap · 1

DDL and DML

DDL (Data Definition Language)

CREATE DATABASE and CREATE TABLE define the structure of your data. Remember to specify data types (e.g., INT, VARCHAR, DECIMAL).

DML (Data Manipulation Language)

INSERT, UPDATE and DELETE manage the actual data inside the table.

Recap · 2

DQL and best practice

The SELECT command retrieves data. You can use it with:

  • WHERE to filter specific rows.
  • COUNT() to count rows.
  • SUM() to add up values (you can do math inside it, like quantity * price).
  • ORDER BY to sort (ASC ascending, DESC descending).

Best practice: always preview your data with a SELECT before running an UPDATE or DELETE to prevent accidental data loss.

Tasks 1 to 5

Your score appears here.

1. Create a new database called shopping_cart.

CREATE DATABASE shopping_cart;
USE shopping_cart; -- Select the DB first

2. Create a table called items within the shopping_cart database with columns: id (integer, primary key), name (varchar), quantity (integer), price (decimal).

CREATE TABLE items (
    id INT PRIMARY KEY,
    name VARCHAR(100),
    quantity INT,
    price DECIMAL(10, 2)
);

3. Use INSERT to add these items: (1, ‘Apple’, 10, 0.99), (2, ‘Banana’, 5, 0.59), (3, ‘Cherries’, 15, 2.99).

INSERT INTO items (id, name, quantity, price)
VALUES
    (1, 'Apple', 10, 0.99),
    (2, 'Banana', 5, 0.59),
    (3, 'Cherries', 15, 2.99);

4. Use UPDATE to change the quantity of Banana to 20.

UPDATE items
SET quantity = 20
WHERE name = 'Banana';

5. Use DELETE to remove Cherries from the table.

DELETE FROM items
WHERE name = 'Cherries';

Answer key · 2

Tasks 6 to 10

6. Use SELECT with a WHERE clause to retrieve all items with a price greater than $1.00.

SELECT * FROM items
WHERE price > 1.00;

7. Use the COUNT function to retrieve the number of items in the items table.

SELECT COUNT(*) FROM items;

8. Use the SUM function to calculate the total value of all items (Total Value = Quantity × Price).

SELECT SUM(quantity * price) AS total_value
FROM items;

9. Use ORDER BY to sort all items by price in ascending order.

SELECT * FROM items
ORDER BY price ASC;

10. Use SELECT * to view the final contents of items and verify that the INSERT, UPDATE and DELETE changes were applied.

SELECT * FROM items;
