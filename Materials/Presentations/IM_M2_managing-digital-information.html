Main lesson · 1

Understanding information systems

An information system (IS) is a combination of hardware, software and network infrastructure that work together to collect, store, process and distribute data.

Data

The raw facts and figures that an IS processes and stores.

Information

The output of the IS, derived from data and used to make decisions.

Key principles

  1. Support of organizational goals: align with the goals to improve efficiency and effectiveness.
  2. Use of technology: leverage the latest technology to improve operations.
  3. Flexibility and adaptability: adapt to changing needs and environments.
  4. Security and control: protect sensitive information.
  5. Continuous improvement: evaluate and improve regularly.

Main lesson · 2

The five main components

These components interact to collect, store, process and distribute data.

ComponentDescriptionRole in the system
HardwareThe physical components (computers, servers, storage devices).Provides the physical infrastructure for the IS to operate.
SoftwareThe programs and applications (operating systems, databases).Provides the functionality and capabilities of the IS.
DataRaw facts and figures.Entered by people, processed by software, retrieved for use.
ProceduresInstructions for how data is input, processed and output.Ensures data is entered correctly and output is accurate and useful.
PeopleThe users and administrators of the IS.Provide input, retrieve output, maintain and manage the system.

Pro tip: Hardware and software process, store and retrieve data as the procedures define, while people use the system to achieve organizational goals.

Main lesson · 3

Advantages and disadvantages

Managing shared information has significant impacts, both positive and negative.

Advantages

  • Improved communication: between departments and individuals.
  • Increased efficiency: automates tasks like data entry and retrieval, saving time and reducing errors.
  • Better decision making: real-time access to accurate data.
  • Cost savings: less manual labor.

Disadvantages

  • High cost: costly to implement and maintain, especially for small organizations.
  • Technical difficulties: complex for non-tech-savvy people.
  • Dependence on technology: downtime or power outages can halt operations.
  • Data security: vulnerable to breaches and cyber-attacks.
  • Data privacy: concerns about storing sensitive personal information.

Main lesson · 4

The role of IS in managing shared information

An IS provides the infrastructure and tools to collect, process, store and disseminate information.

Facilitates collaboration

A centralized place for data storage and access improves accuracy and consistency.

Automates tasks

Handles repetitive work like data entry, increasing efficiency and reducing errors.

Supports strategic decisions

Real-time analytics help managers identify trends, evaluate performance and make informed decisions.

Real-world use case

A retail store manages inventory

  1. A customer buys a shirt. That is the data input.
  2. The software updates the database.
  3. The hardware stores this info.
  4. The procedures ensure the cashier scans the item correctly.
  5. The people (managers) read the resulting information and see the shirt is running low.
  6. They order more from the supplier.

Why it matters

This shared information prevents stockouts and maximizes profit.

FAQs

Common questions

What is the difference between data and information?

Data is raw, unorganized facts (a list of numbers). Information is the processed, organized output that has meaning and supports decisions (a sales report showing trends).

Why are procedures a component of IS?

Without procedures, people wouldn’t know how to use the hardware and software correctly. They are the rulebook for consistency, accuracy and security.

Is data security only an IT department issue?

No. IT manages the technical controls, but every employee (People) plays a role by following procedures and handling sensitive information responsibly.

Create a canteen record table

  1. Select your empty database. Choose New table: items, with 4 columns.
  2. Set item_id INT as PRIMARY key; item_name VARCHAR(60); quantity INT; price DECIMAL(8,2). Save.
  3. Open Insert and enter (1, Rice meal, 10, 50.00), (2, Noodles, 8, 35.00), (3, Fruit cup, 6, 25.00).

Turn records into information
