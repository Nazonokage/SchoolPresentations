Recap · 1

Information systems (IS)

A combination of hardware, software, data, procedures, and people working together to process and distribute information.

Benefits

Improved efficiency, better decision-making, cost savings.

Drawbacks

High implementation cost, technical difficulties, vulnerability to cyber-attacks.

Recap · 2

System Development Life Cycle (SDLC)

Building an IS typically follows these phases: Planning/Analysis, Design, Implementation, and Maintenance.

Feasibility studies

Determine if a project is financially and technically viable.

Prototyping

Creates a working model for early user feedback.

Agile

A modern development method focusing on flexible, incremental releases rather than rigid, linear progress.

Recap · 3

Databases

A database is an organized collection of data.

DBMS

The software (like MySQL) used to manage, retrieve and manipulate the data.

Drivers and connectors

Software components (like ODBC or JDBC) that let applications communicate with the database.

NoSQL databases

Non-relational databases that store data as key-value pairs, documents (like MongoDB) or graphs. Great for unstructured data.

Time-series databases

Optimized for data tracked over time (timestamps).

Create your activity database

Open step-by-step copyable SQL for this activity

  1. Choose New or Databases. Create im_m06_lastname, replacing lastname with your surname using letters, numbers and underscores. Choose utf8mb4_general_ci.
  2. If that database already exists, use a fresh name ending in _v2; keep your previous work.
  3. Select the new database in the left sidebar. Use its SQL tab to enter statements and Go to execute. Save each successful statement in a local queries.sql text file.

Create and populate

  1. Create items with item_id INT PRIMARY KEY, item_name VARCHAR(60), quantity INT and price DECIMAL(8,2).
  2. Insert five fictional school supplies with unique IDs, positive quantities and prices.
  3. Use Browse to check every row and Edit to correct one quantity. Record its before and after values.

Information Management · Module 6 · Recorded activity

Produce an inventory report

  1. Run SELECT item_name, quantity, price, quantity * price AS stock_value FROM items ORDER BY stock_value DESC;
  2. Save the query in queries.sql and capture the result.
  3. Export this database, then follow the restore check at the end of this activity. Verify five restored rows.

Information Management · Module 6 · Recorded activity

Export and restore your work

  1. Select your activity database. Choose Export > Quick > SQL > Go (or Export) and save database.sql.
  2. Choose New and create a separate empty database with _restore added to your activity database name. Select it.
  3. Choose Import > Choose file, select database.sql, then Go. Compare the restored table row counts with the original. Capture the restored database name and data.

Information Management · Module 6 · Recorded activity

If something stops working

  1. Apache or MySQL will not start: capture the Control Panel message and ask the instructor to check the port or service conflict.
  2. Import says table already exists: select a new empty database and import there once.
  3. Foreign-key error: create and populate parent tables first; child values must match existing parent IDs.
  4. Before closing: confirm your submission files are saved outside the browser. Browser history alone is not your activity record.
