# Integrative Programming & Technologies 2 (IPT 2)

**Course Code:** IPT 102 / IT 206 / equivalent  
**Units:** 3  
**Prerequisite:** Integrative Programming & Technologies 1 (IPT 1)

---

## Course Description

This course is a continuation of Integrative Programming and Technologies 1.  
The emphasis is on the use of **scripting languages**, **application programming interfaces (APIs)**, and **programming practices** to facilitate the **management, integration, and security** of the systems that support an organization.

Students will deepen their skills in connecting systems, applying professional coding practices, choosing appropriate technologies, and solving real-world integration problems.

---

## Course Learning Outcomes

By the end of this course, students should be able to:

1. Apply advanced scripting techniques for system management and automation
2. Design, consume, and secure Application Programming Interfaces (APIs)
3. Apply clean coding and professional programming practices in integration projects
4. Evaluate and select appropriate tech stacks for integration scenarios
5. Identify and solve common backend, API, and server problems
6. Apply planning and scaling concepts in integrated systems
7. Implement basic security practices in system integration
8. Build and document a functional integrated system as a capstone project

## Capstone Project Guidelines

Students will design and build a small but complete integrated system that includes:

- Python scripts for automation or data processing
- PHP-based API or web service
- Database integration (MySQL via XAMPP)
- Proper authentication / basic security
- Clean code practices and Git version control
- Responsive interface using Bootstrap (if applicable)
- Documentation (README + basic architecture notes)

**Suggested Themes:**
- Inventory + Sales system with API
- Student information system with external data feed
- Simple booking / reservation system
- Data collection + reporting dashboard

---

## Recommended Teaching Approach

- Start each module with a real-world problem or failure story
- Keep laboratories highly practical (students must code every session)
- Enforce clean Git history and meaningful commits
- Use Postman heavily for API testing
- Encourage code reviews among students
- Relate every topic back to system integration and organizational systems
