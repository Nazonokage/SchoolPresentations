## Period coverage

Prelims: modules 1-4 and OOP foundations. Midterms: methods and access modifiers, based on the midterm HTML and JSON summatives. Pre-finals: static members, constructors, this/super, the four pillars, arrays and pass-by-value, based on OOP_preFi_Summative_Periodical_Prep.html.

Maven and JDBC/DAO are kept in Course_Resources/Additional_Lectures because the available pre-final summative does not establish their period. Static/method topics overlap the midterm review and are linked across periods.
