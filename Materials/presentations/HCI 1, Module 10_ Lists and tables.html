Group it, then tabulate it

Lists group related pieces of information. Tables display large amounts of structured data in rows and columns.

Pro tip: modern context

HTML is for structure and meaning. Use CSS for all visual styling, like bullet types and borders.

Unordered lists

Order does not matter

ul.html
<ul>
  <li>milk</li>
  <li>bread</li>
  <li>butter</li>
  <li>coffee beans</li>
</ul>
Result
  • milk
  • bread
  • butter
  • coffee beans

Wrap and mark

Wrap the list in <ul> and each item in <li>. Like a grocery list: milk before bread makes no difference.

Ordered lists

Sequence is important

ol.html
<ol>
  <li>Gather ingredients</li>
  <li>Mix ingredients together</li>
  <li>Place ingredients in a baking dish</li>
  <li>Bake in oven for an hour</li>
  <li>Remove from oven</li>
</ol>
Result
  1. Gather ingredients
  2. Mix ingredients together
  3. Place ingredients in a baking dish
  4. Bake in oven for an hour
  5. Remove from oven

Historical note

Older HTML used the type attribute for letters or Roman numerals. Today use CSS list-style-type.

Description lists

Name and value pairs

dl.html
<dl>
  <dt>Coffee</dt>
  <dd>A beverage made from roasted, ground coffee beans.</dd>

  <dt>Espresso</dt>
  <dd>A concentrated form of coffee served in small, strong shots.</dd>
</dl>
Result
Coffee
A beverage made from roasted, ground coffee beans.
Espresso
A concentrated form of coffee served in small, strong shots.

Three tags

<dl> is the container. <dt> is the term. <dd> is the definition. Think of a dictionary.

HTML tables

Data in rows and columns

<table>

The main container.

<tr>

Table row.

<th>

Table header for column headings. Bold and centered by default.

<td>

Table data: a standard cell.

Never use tables for layout

Early designers built whole sites with tables. Today tables are strictly for data like schedules, pricing or stats. Use CSS Grid or Flexbox for layout.

Table code

A table with a header row

table.html
<table>
  <!-- First Row: Headers -->
  <tr>
    <th>Month</th>
    <th>Savings</th>
  </tr>

  <!-- Second Row: Data -->
  <tr>
    <td>March</td>
    <td>$200</td>
  </tr>

  <!-- Third Row: Data -->
  <tr>
    <td>April</td>
    <td>$300</td>
  </tr>
</table>
Result
MonthSavings
March$200
April$300

Accessibility tip

Add the scope attribute to headers, like <th scope="col">Month</th>, so screen readers know it heads the whole column.

Table FAQs

Make a table visible

style.css
table, th, td {
  border: 1px solid black;
  border-collapse: collapse;
  padding: 10px;
}

Invisible borders?

Browsers render tables without borders. Add them with CSS.

Squished text?

Add padding to the td and th elements for breathing room.

A list inside a cell?

Yes. Put a ul or ol inside td or th. Great for features in a pricing table.

Real-life scenarios

Hardware store, recipe, dictionary

Unordered list

A bucket of items to buy. Order does not matter.

Ordered list

A recipe. You cannot bake before you mix the batter.

Description list

A dictionary: the word and its meaning.

Pricing page

Three tiers: Basic, Pro and Enterprise. A table aligns features horizontally so users can compare. But use CSS, not a table, to position the header and footer.

Recap

Four things to take with you

Three lists: unordered bullets, ordered numbers, description definitions.
Lists nest: li inside ul or ol.
Tables use table, tr, th and td.

Exercise

Build a page with lists and a table

starter.html
<!DOCTYPE html>
<html>
<head>
  <style>
    table, th, td {
      border: 1px solid black;
      border-collapse: collapse;
      padding: 5px;
    }
  </style>
</head>
<body>
  <h1>My Schedule</h1>
  <!-- Add your table here -->
</body>
</html>

Your page needs

  1. An h1: “My Favorite Recipes”.
  2. An unordered list of your top 3 foods.
  3. An ordered list of steps to make a sandwich.
  4. A table with columns “Class” and “Grade” and 3 data rows.

Bonus

Add a style block with a border so you can see the table.
