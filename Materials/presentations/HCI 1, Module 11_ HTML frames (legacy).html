Legacy features, modern warning

Critical modern warning

<frameset> and <frame> are obsolete and deprecated in HTML5. Browsers barely support them, and they are terrible for layout, accessibility and mobile. Never use them for new projects. You may still meet them in legacy enterprise systems.

Historically, frames divided the browser window into independent rows and columns. Each frame loaded a separate HTML document. The collection was a frameset.

Why they were removed

The disadvantages of frames

Mobile devices

Small screens cannot handle dividing the screen into several frames.

Screen resolutions

Pages looked wildly different on different monitors.

Broken navigation

The Back button often behaved unpredictably.

Browser support

Not all browsers supported them well.

Modern context

They also break SEO, ruin bookmarking because the URL does not change, and make it impossible for screen readers to navigate.

Creating frames

Frameset instead of body

<frameset>

Defines how to divide the window, using the rows or cols attributes. It replaces the body tag.

<frame>

Placed inside the frameset. The src attribute says which HTML document opens in that section.

No body tag

There is no body tag in a frameset document!

Frameset attributes

Dividing the window

AttributeDescription
colsNumber and size of columns: pixels "100, 500", percentages "10%, 80%" or wildcards "10%, *".
rowsNumber and size of rows. Works exactly like cols but for horizontal sections.
borderWidth of the border between frames in pixels, like border="5". 0 means no border.
frameborderWhether a 3D border is displayed: 1 for yes, 0 for no.
framespacingThe empty space between frames.
Frame attributes

Configuring each frame

AttributeDescription
srcThe URL or path of the HTML document to load.
nameNames the frame, like name="main_content". Crucial for links that load a page in another frame.
frameborderOverrides the frameset border setting for this frame.
marginwidthSpace between left and right borders and the content.
marginheightSpace between top and bottom borders and the content.
noresizeLocks the size. Users can drag borders by default.
scrollingScrollbars: yes, no or auto.
longdescLink to a detailed description. An old accessibility attempt.
Example 1

Creating vertical frames

vertical.html
<!DOCTYPE html>
<html>
<head>
  <title>Vertical Frames</title>
</head>
<frameset cols="25%, 50%, 25%">
  <frame src="left_menu.html">
  <frame src="main_content.html">
  <frame src="right_sidebar.html">
</frameset>
</html>

Three columns

The middle column takes up 50 percent of the screen.

Remember

No body tag in a frameset document.

Example 2

Creating horizontal frames

horizontal.html
<!DOCTYPE html>
<html>
<head>
  <title>Horizontal Frames</title>
</head>
<frameset rows="30%, 40%, 30%">
  <frame name="top" src="header.html">
  <frame name="main" src="content.html">
  <frame name="bottom" src="footer.html">
</frameset>
</html>

Three rows

The name attributes are added so links can target them later.

Targeting

A link in one frame opens in another with target="main_frame". The name identifies the target.

How we do it today

Layouts with CSS Flexbox or Grid

modern-layout.html
<!-- Modern Layout Approach -->
<body style="display: flex;">
  <nav style="width: 25%;">Sidebar Menu</nav>
  <main style="width: 75%;">Main Content</main>
</body>

Embedding today

The iframe tag

iframe.html
<!-- Modern Embedding with iframe -->
<iframe
  width="560"
  height="315"
  src="https://www.youtube.com/embed/dQw4w9WgXcQ"
  title="YouTube video player"
  frameborder="0"
  allowfullscreen>
</iframe>

Embed a YouTube video, a Google Map or a widget into a normal page.

Real-life scenarios

Picture-in-picture and a stuck URL

Legacy frameset

Forcing the entire browser window to act like a TV split into three channels at once, all on one remote.

Modern iframe

A small TV (a YouTube video) in your living room. The rest of the page works normally around it.

Why frames broke the web

Click “About Us” in a left frame menu and the right frame loads, but the URL never changes. Bookmark it or send it to a friend and you get the homepage again. A massive UX failure.

Recap

Five things to take with you

Framesets replace the body tag and divide the window by rows and cols.
The frame tag loads individual HTML files into those sections.
Frames are deprecated and obsolete.
Modern layout uses CSS Grid or Flexbox.
Modern embedding uses iframe.
