Rapid recap

Five topics to know

User-centered design

Design based on the specific needs, contexts and feedback of the end-users.

Universal design and accessibility

Usable by all people regardless of age, size or ability. POUR: perceivable, operable, understandable, robust. Assistive technologies like screen readers.

Human error and safety design

Prevent mistakes with form validation and clear labels. Allow recovery with undo and confirmation dialogs.

Evaluating design quality

Strategy for business goals, usability for ease, style for brand, content for readability, SEO for search.

Responsive design

Fluid grids, flexible images like the picture tag, and media queries so a site looks good on every device.

Keep in mind

Responsive means re-arranging

Not just smaller

Responsive design does not only shrink things. It re-arranges them so they fit the screen.

Your best friends

CSS flex-wrap and media queries.

media-skeleton.css
@media screen and (max-width: 768px) {
  /* rules for small screens go here */
}

Answer key: Test III, approach 1

Modern Flexbox (recommended)

columns-flex.html
<!DOCTYPE html>
<html>
<head>
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<style>
  .container {
    display: flex;
    flex-wrap: wrap; /* Allows columns to stack on smaller screens */
  }
  .column {
    flex: 1; /* Each column takes equal space */
    min-width: 250px; /* Breaks to a new line below 250px */
    padding: 15px;
    box-sizing: border-box;
    border: 1px solid #ccc;
  }
</style>
</head>
<body>

<div class="container">
  <div class="column">Column 1</div>
  <div class="column">Column 2</div>
  <div class="column">Column 3</div>
</div>

</body>
</html>

Answer key: Test III, approach 2

Classic media query

columns-media.html
<!DOCTYPE html>
<html>
<head>
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<style>
  .col {
    float: left;
    width: 33.33%; /* Three equal columns by default */
    padding: 10px;
    box-sizing: border-box;
  }

  /* Breakpoint for mobile devices */
  @media screen and (max-width: 768px) {
    .col {
      width: 100%; /* Stacks vertically on smaller screens */
      float: none;
    }
  }
</style>
</head>
<body>

<div class="col" style="background-color:#aaa;">Column 1</div>
<div class="col" style="background-color:#bbb;">Column 2</div>
<div class="col" style="background-color:#ccc;">Column 3</div>

</body>
</html>

Based on Module 18

Three 33.33 percent floated columns, then a breakpoint at 768px that makes each 100 percent wide and removes the float.

Either approach earns full points when it shows the structure and how it adapts.
