Pro tip: modern context

<marquee> and <embed> are legacy or deprecated. Learning them helps you read older code. Modern best practices are included so you know how these effects are achieved today.

The marquee tag

Scrolling text, historically

marquee-syntax.html
<body>
  <marquee direction="down" height="100" width="200" bgcolor="white">Scrolling text</marquee>
</body>

What it does

Defines a scrolling text area that moves horizontally or vertically. By default text scrolls right to left.

Deprecated in HTML5

Obsolete. Poor accessibility, hard to read for users with cognitive disabilities, and no user control over movement. Use CSS animations today.

Live demo

Marquee in action

retro.html
<marquee direction="left" bgcolor="yellow">Welcome to my retro website!</marquee>
Result
Welcome to my retro website!

User control

These buttons are for the demo only. The tag itself gives users no control, which is why it is bad practice.

Embedding multimedia

The embed tag

embed.html
<body>
  <embed src="your-file.mid" width="100%" height="60">
    <noembed><img src="yourimage.gif" alt="Alternative Media"></noembed>
  </embed>
</body>

What it did

Added music or video. The browser includes controls automatically if it supports the media type.

noembed

Fallback content for browsers that did not recognize embed, like an image.

Largely obsolete

Still supported, but the plugins it relied on, like Flash, are gone. Use video and audio.

Embed attributes

And the historical video types

AttributeDescription
aligncenter, left or right.
autostartStart automatically (true or false).
loopPlay continuously, or a number.
playcountTimes to play the sound.
hiddenHide the object.
AttributeDescription
width / heightSize in pixels.
nameReference the object.
srcURL or path of the object.
volumeSound volume, 0 to 100.

Historically: .swf (Flash), .avi, .mov (QuickTime) and .mpeg. Flash is dead. Today the standard is .mp4 (H.264) and .webm.

How we do it today

Modern HTML5 video

video.html
<video width="320" height="240" controls>
  <source src="movie.mp4" type="video/mp4">
  <source src="movie.ogg" type="video/ogg">
  Your browser does not support the video tag.
</video>

No plugins needed

The video and audio tags are built in. The text inside the tag is the fallback if the browser cannot play it.

File path tip

The src must match where the file is saved relative to your HTML file. In a folder called media: src="media/video.mp4"

Real-life scenarios

Tickers, adapters and access

The marquee analogy

Like a news ticker. Great for grabbing attention, terrible for reading a paragraph because you chase the text with your eyes.

Embed vs video

Embed is an adapter to plug an old VCR into a smart TV: clunky. Video is streaming through the smart TV: built in.

Why accessibility matters

A constantly moving marquee is hard for screen readers to parse. CSS animations can be paused or stopped.

Recap

Four things to take with you

Marquee scrolls text but is deprecated, replaced by CSS.
Embed added media but is replaced by video and audio.
Always provide a fallback: noembed, or text inside video.
The src attribute tells the browser where the file is.
Activity: identification

Name the tag or attribute

1. Specifies the direction in which the marquee should scroll.
2. Used to reference the embedded object.
3. Defines a scrolling text area that moves across the page.
4. Refers to Apple’s QuickTime Movie format.
5. References the URL of the object to be embedded.
6. Specifies the number of times to play the sound.
7. Specifies the number of times to loop your marquee.
8. Specifies the type of scrolling, like scroll, slide or alternate.

10. Controls the volume of the sound.
Exercise

Create your own sample HTML

media.html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <title>Retro and Modern Media</title>
  </head>
  <body>
    <marquee direction="left" bgcolor="yellow" loop="infinite">Welcome to my retro website!</marquee>
    <embed src="song.mid" width="100%" height="60">
    <video width="320" height="240" controls>
      <source src="movie.mp4" type="video/mp4">
      Your browser does not support the video tag.
    </video>
  </body>
</html>

Your page needs

  • A marquee scrolling right to left.
  • A different bgcolor.
  • An embed, from a public URL or local file.
  • Below it, a modern video tag with the controls attribute.

Bonus

Add loop="infinite" to the marquee and watch it scroll forever.
