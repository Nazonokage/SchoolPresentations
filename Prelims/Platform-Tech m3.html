B · Main lesson

What is a Database?

Organized collection of structured information, controlled by a DBMS.

💡 Analogy: Database = digital filing cabinet. DBMS = secretary / steward na naghahanap, naglalagay, nagbabantay.

Structured Query Language (SQL)

  • Query: “Database, pakihanap nga lahat ng estudyanteng nakatira sa Iloilo.”
  • Manipulate: mag‑add, mag‑update, mag‑delete
  • Define: gumawa ng bagong table structures
SQL developed at IBM in the 1970s · Oracle · ANSI standard
Types of Database

Mga Uri ng Database

Relational (RDBMS)

Tables, rows, columns, keys. Parang Excel sheets na magkakaugnay.

Object‑oriented

Data as Objects (Java‑style). Swak sa OOP paradigm.

Distributed

Files across different physical sites / servers.

Data Warehouse

Central repository for fast query & business analytics.

NoSQL

Unstructured / semi‑structured data (posts, logs).

Graph

Nodes & edges. Parang Facebook network graph.

Open Source

Libre, open code (PostgreSQL, MySQL).

Cloud Database

DBaaS: AWS, Google — sila na bahala sa hardware.

Multimodel

Combines relational + document models in one backend.

Document/JSON

Stores JSON documents, flexible fields.

Self‑driving

AI / ML automates updates, backup, security.

F · Skill‑building · Answer

Jeziel's Social Media — Possible Solutions

✅ Posibleng Sagot #1: NoSQL Database

Lumipat sa NoSQL Database (tulad ng MongoDB o Cassandra) — mas mabilis mag‑scale ng pahalang (horizontal scaling) at kayang i‑handle ang dynamic na data tulad ng posts at messages.

✅ Posibleng Sagot #2: Graph Database

Gumamit ng Graph Database (tulad ng Neo4j) — lalo na kung ang focus ay sa pag‑track ng friendships, connections, at social relationships.

Paliwanag: Mas flexible ang NoSQL at Graph databases para sa mabilis na paglaki at pagbabago ng istruktura ng data kumpara sa tradisyonal na RDBMS.

F · Skill‑building · Answer

Geff's Multimedia Platform — Possible Solutions

✅ Posibleng Sagot #1: Cloud Object Storage + NoSQL

Gumamit ng Cloud Object Storage (tulad ng AWS S3) para sa physical media files, at NoSQL Document Database para sa metadata management.

✅ Posibleng Sagot #2: Multimodel Database

Gumamit ng Multimodel Database na kayang humawak ng iba't ibang uri ng data — relational para sa user info at document‑based para sa media metadata.

Paliwanag: Mas matipid at mabilis kapag ang mga raw binary files (videos, images) ay naka‑store sa object storage, habang ang metadata ay nasa database para sa mabilis na query at pag‑organize.

1. What is Node.js?

Official Definition

Node.js is a cross‑platform, open‑source server environment that runs on Windows, Linux, Unix, macOS, and more. It's a back‑end JavaScript runtime environment that runs on the V8 JavaScript Engine and executes JavaScript code outside a web browser.

💡 Analogy: Dati, si JavaScript ay parang isang isda na nakatira lang sa loob ng aquarium (ang aquarium ay ang web browser). Hindi siya pwedeng mabuhay sa labas ng browser. Noong ginawa ang Node.js, parang binigyan si JavaScript ng baga o paa para makalabas sa aquarium at maglakad sa lupa (ang lupa ay ang operating system o server). Dahil kay Node.js, pwede mo nang gamitin si JavaScript para gumawa ng server files, mag‑delete ng files, at makipag‑usap nang direkta sa mga databases!
C · Lesson wrap‑up · FAQs

2. Purpose of a Database

Official Definition

Databases are used for storing, maintaining, and accessing any sort of data. They collect information on people, places, or things. That information is gathered in one place so that it can be observed and analyzed.

💡 Analogy: Isipin mo na ikaw ang may‑ari ng isang sikat na Sari‑Sari Store o Grocery. Kung wala kang database, ang listahan ng mga utang, presyo, at imbentaryo mo ay nakasulat lang sa mga pira‑pirasong papel o lumang notebook na pwedeng ngatngatin ng daga, mabasa ng kape, o mawala bigla. Ang pangunahing layunin (purpose) ng database ay ilagay ang lahat ng magulong impormasyon na ito sa isang matibay, secure, at digital na taguan.
  • Storing (Pagtatabi): Ligtas na nakatago ang pangalan ng customer, items, at mga presyo.
  • Maintaining (Pag‑aayos): Madali mong mapapalitan ang presyo kapag nagka‑inflation nang hindi binubura ang buong listahan.
  • Accessing (Pagkuha): Sa isang click o query mo lang, malalaman mo agad kung sino ang pinakamalaking umutang sa tindahan mo para mabilis mong ma‑analyze kung kumikita ka pa ba o nalulugi na!
