## Part IV — Enumeration (10 pts)

### A. 4 Types of NoSQL Databases (4 pts — 1 pt each)

1. Document Database
2. Graph Database
3. Key-Value Store
4. Wide-Column Store

> Order does not matter. All four must be named for full credit.

6. Cloud Functions
7. Analytics
8. Performance Monitoring
9. Remote Config
10. Cloud Messaging (FCM)

### C. 3 Front-End Web Languages + Roles (3 pts — 1 pt per correct pairing)

| Language | Role |
|----------|------|
| **HTML** | Structure / Skeleton of the page (content, layout, elements) |
| **CSS** | Styling / Appearance (colors, fonts, spacing, layout) |
| **JavaScript** | Behavior / Logic (interactivity, functions, dynamic content) |

> For full credit, the language AND a reasonable description of its role must be correct. Mislabeled roles (e.g., "HTML = styling") earn 0 for that item.
