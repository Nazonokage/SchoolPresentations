# ☕ Object-Oriented Programming — EL101

Lecture modules, slides, reviewers, and exam materials for **Object-Oriented Programming (EL101)**.
Covers OOP fundamentals, access modifiers, static vs. instance members, methods & arrays, Maven build automation, PHP/XAMPP polymorphism, and database access via JDBC/DAO.

## ⚡ Quick start

1. **Browse the module list below** and click the one you need.
2. `.html` files → open in your **browser** (they're interactive slide decks).
3. `.md` / `.docx` / `.txt` files → readable or downloadable right here on GitHub.
4. Need review material? Head to the [`prelims/`](prelims/) folder.

No downloads or installs required — everything renders in-browser.
