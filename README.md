## Organization

Each branch keeps its local period folders (Prelims, Midterms, Pre_Finals), shared resources, or module structure inside Materials. Previously uploaded files stay at their original paths. New branches contain their subject only. This main branch is the subject directory.

Local application dependencies, caches, Git metadata, secrets and temporary files are not uploaded. Teaching source files and companion assets are retained together. Branch SYNC-MANIFEST.json files record the included file hashes and local exclusions.
