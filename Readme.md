# 🔐 Systems Integration & Architecture — IT108

Lecture modules, slides, reviewers, and exam materials for **Systems Integration & Architecture (IT108)**.

Covers System Integration concepts, SOA, Middleware, Testing & QA, Software Usability, REST APIs, Microcontrollers, Arduino, E-Commerce, MySQL, SQLite/WAMP, NoSQL, Web Frameworks, and Node.js Web Services.

---

## ⚡ Quick start

1. **Browse the module list below** and click the one you need.
2. `.html` files → open in your **browser** (they're interactive slide decks).
3. Need review material? Head to the [prelims/](prelims) folder.

No downloads or installs required — everything renders in-browser.
