🗃️ Backup

Creating duplicate copies of data and storing them on separate physical or cloud storage. Acts as a safety net against human error, hardware failure, corruption, and cyberattacks.

🔄 Recovery

Restoring backed-up data back into a target database engine to return an application to an operational or point-in-time state.

💡 Key Takeaway: A database is only as reliable as its restore process. The best backup is the one you've tested and confirmed restores correctly.

Drill 1 — PHP Backup via MySQLi

Programmatic Backup Script

What It Does
  • Connects to MySQL via mysqli_connect()
  • Fetches all table names with SHOW TABLES
  • Exports each table's CREATE statement
  • Exports each row as an INSERT statement
  • Writes everything to a timestamped .sql file
Key Functions Used
  • mysqli_connect() — opens DB connection
  • mysqli_query() — executes SQL statements
  • mysqli_fetch_row() — reads table names
  • mysqli_real_escape_string() — sanitizes values
  • fopen() / fwrite() / fclose() — file I/O
PHP — backup_mysqli.php
// ── Configuration ─────────────────────────────
$host     = 'localhost';
$username = 'db_user';
$password = 'secret_password';
$database = 'app_production';

$connection = mysqli_connect($host, $username, $password, $database);
if (!$connection) die("Connection failed: " . mysqli_connect_error());

function backupDatabase($connection, $database) {
    // Step 1: Create timestamped file
    $backupFile = 'backup_' . date('Ymd_His') . '.sql';
    $handle     = fopen($backupFile, 'w');

    // Step 2: Fetch all table names
    $tables = [];
    $result = mysqli_query($connection, "SHOW TABLES");
    while ($row = mysqli_fetch_row($result)) { $tables[] = $row[0]; }

    foreach ($tables as $table) {
        // Step 3: Export CREATE TABLE structure
        $res = mysqli_query($connection, "SHOW CREATE TABLE `$table`");
        $row = mysqli_fetch_row($res);
        fwrite($handle, "\n\n" . $row[1] . ";\n\n");

        // Step 4: Export each row as INSERT
        $res = mysqli_query($connection, "SELECT * FROM `$table`");
        while ($row = mysqli_fetch_assoc($res)) {
            $vals = array_map(fn($v) =>
                "'" . mysqli_real_escape_string($connection, $v) . "'",
                array_values($row)
            );
            fwrite($handle, "INSERT INTO `$table` VALUES (".implode(",",$vals).");\n");
        }
    }
    fclose($handle);
    echo "Backup generated: " . $backupFile;
}

backupDatabase($connection, $database);
mysqli_close($connection);
Drill 2 — PHP Recovery via MySQLi

Programmatic Recovery Script

Recovery Flow
  • Check if the backup .sql file exists
  • Read its full contents with file_get_contents()
  • Split into individual queries on ;\n delimiter
  • Execute each query in sequence via mysqli_query()
  • Report any per-query errors immediately
Common Pitfalls
  • Splitting on ; alone breaks multi-line queries
  • Must trim() each query before executing
  • Restore to an empty database to avoid conflicts
  • Large files may hit memory_limit — increase in php.ini
PHP — recover_mysqli.php
$host       = 'localhost';
$username   = 'db_user';
$password   = 'secret_password';
$database   = 'app_production';
$backupFile = 'backup_20260728_120000.sql';

$connection = mysqli_connect($host, $username, $password, $database);
if (!$connection) die("Connection failed: " . mysqli_connect_error());

function recoverDatabase($connection, $backupFile) {
    // Step 1: Validate backup file exists
    if (!file_exists($backupFile)) {
        die("Error: Backup file '{$backupFile}' not found.");
    }

    // Step 2: Read entire SQL file into memory
    $sqlContent = file_get_contents($backupFile);

    // Step 3: Split into individual queries
    $queries = explode(";\n", $sqlContent);

    // Step 4: Execute each query
    foreach ($queries as $query) {
        $query = trim($query);
        if (!empty($query)) {
            if (!mysqli_query($connection, $query)) {
                echo "Error: " . mysqli_error($connection) . "\n";
            }
        }
    }
    echo "Recovery completed successfully!\n";
}

recoverDatabase($connection, $backupFile);
mysqli_close($connection);
Drill 3A — CLI Backup via mysqldump

Fast Production Backup with mysqldump

⚡ Why mysqldump?

Native MySQL tool — faster, more reliable, handles edge cases like stored procedures, views, and triggers that a manual PHP script might miss.

🔧 PHP system() Function

Executes an external shell command from PHP. Returns the last line of output; second argument captures the exit code (0 = success).

Script Breakdown
  • sprintf() builds the shell command string safely
  • escapeshellarg() wraps each argument to prevent injection
  • system($cmd, $code) runs the command and captures exit code
  • $code === 0 means the dump succeeded
  • Output file: backup_YYYYMMDD_HHMMSS.sql
Security Considerations
  • Always use escapeshellarg() on every argument
  • Never interpolate user input directly into shell commands
  • Store credentials in config files outside the web root
  • Consider using ~/.my.cnf for passwordless CLI access
PHP — backup_dump.php
$host       = 'localhost';
$username   = 'db_user';
$password   = 'secret_password';
$database   = 'app_production';
$backupFile = 'backup_' . date('Ymd_His') . '.sql';

// Build the shell command with safe argument escaping
$command = sprintf(
    "mysqldump --host=%s --user=%s --password=%s %s > %s",
    escapeshellarg($host),
    escapeshellarg($username),
    escapeshellarg($password),
    escapeshellarg($database),
    escapeshellarg($backupFile)
);

// Execute and capture exit code
system($command, $outputCode);

if ($outputCode === 0) {
    echo "Backup created: {$backupFile}";
} else {
    echo "Error generating backup via mysqldump.";
}
Drill 3B — CLI Recovery via mysql

Fast Production Recovery with mysql CLI

📥 mysql CLI Import

The mysql command reads a .sql file and executes it against the target database. The < operator redirects file content into the command.

🧪 Comparing Approaches

PHP mysqli: More control, works without CLI access, but slower on large datasets.
mysqldump/mysql CLI: Faster, more reliable, handles complex schemas better.

PHP — recover_dump.php
$host       = 'localhost';
$username   = 'db_user';
$password   = 'secret_password';
$database   = 'app_production';
$backupFile = 'backup_20260728_120000.sql';

// Build the restoration command
$command = sprintf(
    "mysql --host=%s --user=%s --password=%s %s < %s",
    escapeshellarg($host),
    escapeshellarg($username),
    escapeshellarg($password),
    escapeshellarg($database),
    escapeshellarg($backupFile)
);

system($command, $outputCode);

if ($outputCode === 0) {
    echo "Database restored from: {$backupFile}";
} else {
    echo "Error restoring database via mysql CLI.";
}
Backup vs Recovery — Key Difference
  • Backup uses > (output to file) with mysqldump
  • Recovery uses < (input from file) with mysql
  • Same config, opposite direction of data flow
Recommended Best Practices
  • Schedule backups with CRON jobs (Linux) or Task Scheduler (Windows)
  • Store backups off-site or in cloud storage (S3, Google Drive)
  • Test restores regularly — a backup you haven't tested is not a backup
Lesson Wrap-Up

Frequently Asked Questions

❓ Why is automated backup essential in PHP applications?

Manual backups are prone to human omission. Automated PHP scripts or CRON jobs ensure regular, consistent backups without requiring manual intervention — even when the developer is asleep or on vacation.

❓ How frequently should database backups be performed?

It depends on data velocity. High-transaction systems (e-commerce, banking) need real-time logging or hourly incremental backups. Low-change static systems may only need daily or weekly full backups.

❓ Can a database be recovered without a backup file?

Without a clean backup or binary log stream, recovery is extremely difficult, costly, and often incomplete using forensic disk recovery software. This is why proactive backups are non-negotiable.

❓ Which method is better — PHP mysqli or mysqldump?

For production systems, mysqldump is faster and more complete. PHP mysqli backup is useful when you lack CLI access or need fine-grained control over the export format.
