B.1 · Main Lesson

What Is a Web Service?

Plain definition

Internet software that uses standardized messaging protocols, made available from a provider's web server for use by a client or other web‑based programs.

Scale ranges from massive enterprise systems (storage, CRM) down to tiny services like a single stock quote. Also called application services.

Technical definition

A web service (WS) is either:

  • A service offered by one electronic device to another, over the internet, or
  • A server listening for requests on a network port, serving HTML, JSON, XML or images
The Misnomer: "Web" in Web Service is misleading — these are not for the graphical WWW people browse. They're machine‑to‑machine services running over the internet using standard protocols.
B.1 · How They Work

The Protocol Toolkit

XML

Tags, codes, and decodes the data being exchanged.

SOAP

Transfers the data — lets different languages talk with minimal effort.

WSDL

Tells the client what the service includes and how to connect.

UDDI

A registry listing which services exist, so others can discover them.

REST

Lightweight, scalable style built on HTTP — often trades XML for JSON.

Not every web service uses all five — REST‑based APIs are the modern default.

B.1 · Requirements

Core Components of a Web Service

  • Is accessible over the web
  • Uses XML (increasingly JSON) for exchange
  • Is interoperable across languages & OSes
  • Is self‑contained and self‑describing
  • Is discoverable via a mechanism like UDDI
  • Miss one of these and it's not really a "web service" in the formal sense.

B.2 · Main Lesson

What Is Node.js?

Runtime, not a browser

An open‑source, cross‑platform runtime environment for running JavaScript outside the browser — used for server‑side, non‑blocking, event‑driven apps and APIs.

Built on Chrome's V8 engine: write frontend and backend in one language, one unified stack.

(JavaScript)
⇄

(also JavaScript)

Same language, both sides — quick, easy, maintainable.

B.2 · Key Features

Why Node.js Feels Fast

Non‑blocking I/O

Serves many concurrent events on a single thread without waiting on slow reads — fast & scalable for data‑heavy work.

Built for real‑time

Push‑based architecture — excels at web sockets, live chat, and real‑time collaboration.

Open source

Constantly improved by a large, global developer community.

B.3 · Node.js Modules

Three Kinds of Modules

Core Modules

Bare‑bones functionality built into Node.js — e.g. fs, http. Loads automatically at startup.

Local Modules

Modules you create inside your own app, splitting features into separate files/folders.

Third‑Party Modules

Code from other developers you import to extend your app — e.g. the express framework.

Worker Threads let CPU‑heavy tasks run in parallel, without disturbing the main event loop.

B.5 · The fs Module

Three Ways to Touch a File

Synchronous

Blocks the event loop until the file operation finishes. Function names end in Sync.

fs.readFileSync()

Callback API

Asynchronous — pass a callback as the final argument; execution keeps moving.

fs.readFile()

Promise‑based

Asynchronous — modern async/await syntax via fs/promises.

fs.readFile() .then()

All three read the same file — they just differ in whether Node.js waits around for the answer.

D · Wrap‑Up

Frequently Asked Questions

Node.js vs. JSON — what's the difference?

Node.js is a runtime that executes JavaScript on a server. JSON is a text‑based data format. Node.js often uses JSON to move data — but one runs code, the other stores it.

Why both sync and async APIs?

Synchronous is simpler but freezes the server while it waits. Asynchronous (callback/promise) lets Node.js keep serving other requests. Async is preferred in production.

What does module.exports do?

It's a built‑in object you use in a local module to say exactly which functions or variables other files can require(). Skip it, and nothing is shared.

Answer Key · Part 1

Checking Your Work

Q1

B — Machine‑to‑machine interaction

Web Services don't use the human‑facing WWW; they let machines talk via standard protocols like HTTP, SOAP, and REST.

Q2

B — A discoverable registry

UDDI is the discovery mechanism that lets services list themselves so other programs can find them.

Q3

Node.js runs code; JSON stores data

Node.js is a runtime for executing JavaScript server‑side. JSON is a lightweight text format for storing/transmitting data. Node.js uses JSON heavily, but they serve entirely different purposes.

Q4

B — stringify() then parse()

JSON.stringify() serializes an object to a string; JSON.parse() deserializes a string back into an object.

Answer Key · Part 2

Checking Your Work

Q5

C — Core Modules

Modules like fs, http, and path are built into the Node.js binary — no separate install needed.

Q6

C — Asynchronous / Callback API

Callback (and Promise‑based) APIs don't block the event loop, so the server can keep handling other requests while a file is read.

Q7

B — Real‑time collaboration & live chat

Node.js was designed for push‑based, event‑driven work — it shines with live connections, real‑time collaboration tools, IoT sensors, and SPAs needing constant back‑and‑forth data.
