📈 implicit conversion

public class Module2_1 { public static void main(String args[]) { int num1 = 201; double d_num1 = num1; // automatic widening System.out.println("double: " + d_num1); } }
no explicit cast needed — double has larger range

⚙️ explicit conversion

public class Module2_2 { public static void main(String args[]) { int num = 42; double d = (double) num; // explicit cast Double wrapped = Double.valueOf(num); System.out.println("cast: " + d); System.out.println("wrapper: " + wrapped); } }
explicit cast (double) or Double.valueOf()

🔍 when to use

implicit safe, automatic, no data loss
explicit required when narrowing (double → int) or for clarity

narrowing · overflow · char
06 / 09

⚠️ narrowing (double → int)

public class Narrowing { public static void main(String args[]) { double pi = 3.14159; int intPi = (int) pi; // explicit cast required System.out.println(intPi); // 3 (truncated) } }
🔸 fractional part lost — data truncation

💥 overflow / underflow

public class Overflow { public static void main(String args[]) { int big = 2_000_000_000; int overflow = big * 2; // wraps around System.out.println(overflow); // -294967296 long safe = (long) big * 2; // cast before multiplication System.out.println(safe); // 4000000000 } }
🔸 cast to larger type (long) before operation

🔤 char ↔ int conversion

char c = 'A'; int ascii = (int) c; // 65 char back = (char) (ascii + 1); // 'B' System.out.println(ascii + " → " + back);

07 / 09

🧮 automatic promotion

public class Promotion { public static void main(String args[]) { byte b = 10; int i = 5; double d = 2.5; // b + i → int, then + d → double double result = b + i + d; System.out.println(result); // 17.5 // byte + byte → int (must cast back) byte b1 = 10, b2 = 20; byte sum = (byte) (b1 + b2); // explicit cast needed } }

📊 promotion rules

  • byte, short, char → int when operated
  • if either operand is long → result is long
  • if either operand is float → result is float
  • if either operand is double → result is double
rule binary numeric promotion: convert to the largest type
⚡ always be aware of the type before arithmetic — cast early to avoid surprises
