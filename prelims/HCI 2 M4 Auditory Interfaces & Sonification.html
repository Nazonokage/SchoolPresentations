Type 1 direct translation
Audification
Definition
An auditory display technique for representing a sequence of data values as sound. It is a "direct translation" of a data waveform to the audible domain.
How it works
  • Interprets a data sequence as an audio waveform — input directly mapped to sound pressure levels.
  • Allows the listener to hear periodic components as frequencies.
  • Requirement: Works best with large data sets that have repeating patterns.
Example
🌍 Seismic / Earthquake Data
The vibrations of the ground during an earthquake have a waveform. When you speed up the playback of seismic data, you can hear it as a rumble or roar — audification of an earthquake.
⚡ Direct representation without converting to visuals
⟡ purpose: simplest way to get a direct representation of data
Type 2 non-speech audio
Sonification
Definition
The use of non-speech audio to convey information or perceptualize data.
Advantages
Our auditory perception excels at:
  • Temporal (time) & Spatial (location)
  • Amplitude (loudness) & Frequency resolution
A great alternative or addition to visual data visualization.
Challenges & Example
⚠ The Challenge
The sonification community (e.g., ICAD) faces hurdles — it's difficult to present and analyze data using only sound. Many attempts must be coded from scratch due to lack of standard tools.
📡 Example: Geiger Counter
The rate of clicks indicates radiation level. Faster clicks (click-click-click) mean higher radiation.
Type 3 auditory icon
Earcon
Definition & Origin
A brief, distinctive sound that represents a specific event or conveys information.
Origin: A pun on the familiar term "icon". If a visual icon is an "eye-con", the auditory counterpart is an "earcon" — coined by D.A. Sumikawa in 1985.
Characteristics
Typically synthesized tones or sound patterns.
Examples
  • 🖥 Operating Systems
    The simple beep on error, or sound schemes for startup, shutdown, low battery.
  • 📺 Broadcast Media Cues
    Alert signal for Emergency Broadcast System.
    Iconic three-tone melody (chime) identifying NBC broadcasts.
Type 4 voice messaging
Voicemail System
Definition
Also known as a voice message or voice bank. A computer-based system that allows users and subscribers to exchange personal voice messages.
Functionality
Can deliver voice information and process transactions using just an ordinary telephone.
Broad Concept
Any system that transports stored telecommunications voice messages — including old answering machines.
Modern Context & Example
📱 Modern Context
Almost all cell phone services include voicemail. Many corporate PBX systems include versatile internal voice-messaging services.
📞 Example: *98 Vertical Service Code
In US landlines, subscribers dial *98 to access their voicemail box — to listen, select, or delete messages.

Sonify Data Points
Mapping data values to oscillator frequency and gain.
// Map data to sound parameters
function sonify(data) {
  const ctx = new AudioContext();
  const osc = ctx.createOscillator();
  const gain = ctx.createGain();
  osc.frequency.setValueAtTime(
    200 + data.value * 800, ctx.currentTime
  );
  gain.gain.setValueAtTime(
    data.intensity * 0.8, ctx.currentTime
  );
  osc.connect(gain);
  gain.connect(ctx.destination);
  osc.start();
  osc.stop(ctx.currentTime + 0.3);
}
Concept
From Data to Sound
  • Frequency maps to data value — higher values produce higher pitches.
  • Gain (volume) maps to intensity — louder for stronger signals.
  • Duration can map to event length or persistence.
⟡ Used in data-driven sonification — turning numbers into audible soundscapes.
