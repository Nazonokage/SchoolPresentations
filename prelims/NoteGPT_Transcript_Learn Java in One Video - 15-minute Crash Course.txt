## Slide 2: What You Need to Get Started

**Title:** Setting Up Your Java Environment

**Before you can code, you need:**
1. **Java Development Kit (JDK):** The software that lets you write and run Java programs.
2. **An IDE (Integrated Development Environment):** A program that makes coding easier.

**What is an IDE?**
- Like Microsoft Word for writing code.
- It helps with:
    - Auto-completing code.
    - Finding errors.
    - Running your programs.
- **Recommended IDE:** **Eclipse** (shown in this tutorial) or IntelliJ IDEA.

**Next Step:** Install the JDK and Eclipse (takes just a few minutes).

## Slide 3: Your First Java Project

**Title:** Creating Your First Java Program in Eclipse

**Step-by-Step Instructions:**

1.  **Open Eclipse.**
2.  **Create a New Project:**
    - Right-click in the **Package Explorer**.
    - Go to `New` ➡ `Java Project`.
    - Name it (e.g., `ProjectPineapple`).
    - Uncheck the "module" option (not needed for beginners).
    - Click `Finish`.
3.  **Create a New Class:**
    - Right-click the `src` (source) folder.
    - Go to `New` ➡ `Class`.
    - Name it (e.g., `AwesomeJavaProgram`).
    - **Important:** Check the box: `public static void main(String[] args)`.
    - Click `Finish`.

**What just happened?**
Eclipse generated a "skeleton" (template) for a working Java program.

## Slide 4: Understanding the Main Method

**Title:** The Main Method: Where Your Program Starts

**What is the Main Method?**
- It's the **entry point** of your Java program.
- When you run your program, Java executes everything inside the `main` method.

**Anatomy of a Main Method:**
```java
public static void main(String[] args) {
    // Your code goes here!
}
```
- **`public`:** Accessible from anywhere.
- **`static`:** Can be called without creating an object.
- **`void`:** Returns nothing.
- **`main`:** The name of the method.
- **`String[] args`:** Command-line arguments (we'll ignore for now).

**Pro Tip:** Almost all your code will go inside these curly braces `{ }`.

## Slide 5: Variables - Storing Data

**Title:** Java Basics: Variables

**What is a Variable?**
- A container that stores data.
- Has a **name**, a **type**, and a **value**.

**Syntax:**
```java
type variableName = value;
```

**Example:**
```java
int myInt = 7;
```
- **`int`:** The type (integer/number).
- **`myInt`:** The name.
- **`7`:** The value.
- **`;`:** Ends the statement (most lines end with one).

**Using the Variable:**
```java
System.out.println(myInt);
```
- `System.out.println()` prints to the console.
- This prints `7`.

---

## Slide 6: Java Data Types (Primitives)

**Title:** Primitive Data Types: The Basics

**What are Primitive Types?**
- They're the **building blocks** of Java.
- They start with a **lowercase** letter.

**Common Primitive Types:**

| Type | Description | Example |
| :--- | :--- | :--- |
| **`int`** | Integer (whole numbers) | `int age = 25;` |
| **`double`** | Decimal numbers | `double price = 19.99;` |
| **`char`** | A single character | `char initial = 'J';` |
| **`boolean`** | True or False | `boolean isRaining = false;` |

**Sample Code:**
```java
int myInt = 7;
double shoeSize = 9.5;
char myInitial = 'J';
boolean isJavaFun = true;
```

**Note:** There are 8 primitive types total in Java.

## Slide 7: Variables Interacting

**Title:** Making Variables Work Together

**You can perform calculations on variables.**

**Example (Multiplication):**
```java
int myInt = 7;
double shoeSize = 9.5;

// Calculate and print directly
System.out.println(myInt * shoeSize); // Outputs: 66.5

// Or store the result
double result = myInt * shoeSize;
System.out.println(result); // Outputs: 66.5
```

**Operators:**
- **`+`** : Addition
- **`-`** : Subtraction
- **`*`** : Multiplication
- **`/`** : Division

## Slide 8: Strings - Working with Text

**Title:** The String Type (Non-Primitive)

**What is a String?**
- Holds text (sequences of characters).
- **Starts with a capital 'S'** (not primitive).

**Syntax:**
```java
String myName = "John";
```
- Use **double quotes** `" "` for Strings.

**String Methods:**
- Strings have built-in "actions" called **methods**.
- Use a dot `.` to access them.

**Sample Code:**
```java
String myName = "John";

// Get the length
System.out.println(myName.length()); // Outputs: 4

// Convert to uppercase
System.out.println(myName.toUpperCase()); // Outputs: JOHN
```

**Pro Tip:** Type your variable name + a period `.` in Eclipse to see all available methods.

---

## Slide 9: Creating Your Own Methods

**Title:** Methods: Reusable Actions

**What is a Method?**
- A block of code that performs a specific task.
- You can call it whenever you need it.

**Creating a Simple Method:**
```java
private static void burp() {
    System.out.println("Burp!");
}
```

**Method Declaration Breakdown:**
- **`private`:** Only accessible within this file.
- **`static`:** Can be called without creating an object.
- **`void`:** Returns nothing.
- **`burp`:** Method name.
- **`()`:** Empty parentheses (no parameters).

**Calling the Method:**
```java
public static void main(String[] args) {
    burp(); // Now our program will print "Burp!"
}
```

---

## Slide 10: Methods with Parameters

**Title:** Sending Data to Methods

**What are Parameters?**
- Information you pass into a method.
- Makes methods more flexible.

**Method with Parameters:**
```java
private static void printName(String name, int number) {
    System.out.println("My name is " + name + " and my number is " + number);
}
```

**Calling It:**
```java
public static void main(String[] args) {
    printName("John", 7);
    // Outputs: My name is John and my number is 7
}
```

**Key Concepts:**
- Separate multiple parameters with commas `,`.
- **Concatenation:** Joining strings with `+`.

---

## Slide 11: Methods That Return Values

**Title:** Getting Data Back from Methods

**What is a Return Value?**
- Some methods give you back a result.

**Method That Returns a String:**
```java
private static String getName() {
    return "My name is John";
}
```

**Using the Returned Value:**
```java
public static void main(String[] args) {
    String result = getName();
    System.out.println(result); // Outputs: My name is John
}
```

**Important:**
- Change `void` to the **return type** (e.g., `String`, `int`).
- Use the `return` keyword.
- The caller can store or use the returned value.

## Slide 12: Conditional Statements (If/Else)

**Title:** Making Decisions with If/Else

**What are Conditionals?**
- They let your program make decisions.
- **"If this condition is true, do this."**

**Syntax:**
```java
if (condition1) {
    // Runs if condition1 is true
} else if (condition2) {
    // Runs if condition2 is true
} else {
    // Runs if none are true
}
```

**Example (Strings):**
```java
String name = "John";

if (name.equals("John")) {
    System.out.println("This guy is awesome!");
} else if (name.equals("Larry")) {
    System.out.println("This guy is okay, I guess.");
} else {
    System.out.println("I don't know this guy at all.");
}
```

**Note:** Use `.equals()` for String comparison, not `==`.

---

## Slide 13: Conditionals with Numbers

**Title:** Comparing Numbers

**Comparison Operators for Numbers:**
- **`==`** : Equal to
- **`!=`** : Not equal to
- **`>`** : Greater than
- **`<`** : Less than
- **`>=`** : Greater than or equal to
- **`<=`** : Less than or equal to

**Example:**
```java
int number = 7;

if (number == 5) {
    System.out.println("Number is 5");
} else if (number > 5) {
    System.out.println("Number is greater than 5");
} else {
    System.out.println("Number is less than 5");
}
```

**Important:** Use double equals `==` for comparison (single equals `=` is for assignment).

## Slide 14: Loops (Repeating Code)

**Title:** Loops: Doing Things Multiple Times

**What is a Loop?**
- Repeats a block of code multiple times.
- Saves you from copying and pasting.

**The For Loop:**
```java
for (int i = 0; i < 10; i++) {
    System.out.println("These pretzels are making me thirsty!");
}
```

**How It Works:**
1.  **`int i = 0;`** : Start with `i` at 0.
2.  **`i < 10;`** : Keep looping while `i` is less than 10.
3.  **`i++`** : Add 1 to `i` after each loop.
- This prints the message **10 times**.

**Change the Loop:**
- Want 100 times? Change `10` to `100`.
- Want to print the loop number? Use `i`.

## Slide 15: Object-Oriented Programming (OOP)

**Title:** Understanding Classes and Objects

**What is Object-Oriented Programming?**
- Organizes code into "objects" that have:
    - **Attributes:** Data (e.g., name, age).
    - **Methods:** Actions (e.g., meow, run).
- Java is an **Object-Oriented** language.

**Class vs. Object:**
- **Class:** A blueprint/template.
- **Object:** An actual instance created from the blueprint.

**Analogy:**
- **Class:** Cookie cutter.
- **Object:** The actual cookie you cut out.
- You can make many cookies from one cutter!

## Slide 16: Creating a Custom Class

**Title:** Creating Your Own Class

**Step-by-Step Instructions:**

1.  **Right-click the `src` folder.**
2.  **Go to `New` ➡ `Class`.**
3.  **Name it (e.g., `Cat`).**

**The `Cat` Class (Blueprint):**
```java
public class Cat {
    String name;
    int age;

    public void meow() {
        System.out.println("Meow!");
    }
}
```

**What This Means:**
- **`String name;`** : Every Cat has a name.
- **`int age;`** : Every Cat has an age.
- **`public void meow()`** : Every Cat can meow.

## Slide 17: Creating Objects from a Class

**Title:** Using Your Class to Create Objects

**Creating Cat Objects (in your main method):**
```java
public static void main(String[] args) {
    // Create first cat
    Cat myCat = new Cat();
    myCat.name = "Fred";
    myCat.age = 6;

    // Create second cat
    Cat anotherCat = new Cat();
    anotherCat.name = "Stella";
    anotherCat.age = 5;
}
```

**How It Works:**
- **`Cat myCat = new Cat();`** : Creates a new Cat object.
- **`myCat.name = "Fred";`** : Sets its name.
- **`myCat.age = 6;`** : Sets its age.

**Use Them Later:**
```java
System.out.println(myCat.name); // Outputs: Fred
System.out.println(anotherCat.age); // Outputs: 5
myCat.meow(); // Outputs: Meow!
```

## Slide 18: Understanding Static vs. Non-Static

**Title:** Static vs. Non-Static Methods

**What's the Difference?**
- **`static`:** Belongs to the **class itself**.
- **Non-static:** Belongs to **individual objects** created from the class.

**Example in Your `Cat` Class:**
```java
public class Cat {
    // Non-static (belongs to a specific cat)
    public void meow() {
        System.out.println("Meow!");
    }

    // Static (belongs to the Cat class itself)
    public static void dingDong() {
        System.out.println("Ding dong!");
    }
}
```

**How to Call Them:**
```java
// Calling static method (on the class)
Cat.dingDong(); // Works fine!

// Calling non-static method (on an object)
Cat.meow(); // ERROR! Can't call on the class.

// Instead, create an object first
Cat myCat = new Cat();
myCat.meow(); // Works!
```
