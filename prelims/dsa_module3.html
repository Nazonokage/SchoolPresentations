⚙️ algorithm vs. data structure

an algorithm is a tool to resolve a problem with data. a data structure is the art of organizing that data in the first place.

📦 what is a data structure?

a specialized format for organizing, processing, retrieving, and storing data — arranged to suit a specific purpose so it's easy to access and work with.

algorithm design
characteristics of an algorithm
02 / 09

not every procedure counts as an algorithm — it needs to check these boxes:

🎯 clarity & direction

  • unambiguous — every step, input, and output has exactly one meaning
  • independent — the steps stand on their own, not tied to any one programming language

🔄 inputs & outputs

  • input — 0 or more well-defined inputs
  • output — 1 or more well-defined outputs, matching what's expected

⏱️ finiteness

the algorithm must terminate after a finite number of steps — it can't run forever.

✅ feasibility

it must be achievable with the resources you actually have available.

📝 pseudocode

01START
02Declare three integers a, b & c
03Define values of a & b
04Add values of a & b
05Store output of Step 4 to c
06Print c
07STOP
the algorithm follows chronological order — each step depends on the one before it.

➗ what's a math expression?

a combination of one or more operators: +-*/%&&||

the result comes from the operands — which might be numbers, but can also be characters, strings, or booleans.

🧩 methods vs. functions

a method is a block of code that only runs when it's called. you can pass data into it as parameters.

methods exist so you can define code once and reuse it — instead of writing the same logic over and over.

📚 where these live

Java ships a built-in Math class packed with ready-made methods — no need to write your own for the common stuff.

08 / 09

☕ Module3_2.java

public class Module3_1 { public static void main(String args[]) { int x = 100; int y = 200; System.out.println("Using the defined method -> max_data"); int result = max_data(x, y); System.out.println("Max data is + " + " " + result); } static int max_data(int n1, int n2) { if (n1 > n2) { return n1; } else { return n2; } } }

🔬 anatomy of a method

  • static int — return type: gives back a whole number
  • max_data(int n1, int n2) — name + parameters it accepts
  • if / else — decides which value to hand back
  • return — sends the result to whoever called it
yes you can absolutely write your own — this is exactly how Math.max() works under the hood
